# W-Game v0.1 详细配置和测试指南

## 项目概述

W-Game是基于Cocos Creator 3.8.7的4×4网格单词查找游戏。本指南将详细说明每个场景、节点、组件的具体配置步骤。

---

## 第一部分：场景和UI配置详细步骤

### 1. 创建LetterTile预制体

#### 1.1 创建预制体文件
1. **资源管理器** > 右键 > **创建** > **预制体**
2. 命名：`LetterTile`
3. 双击打开预制体编辑器

#### 1.2 配置预制体节点结构
```
LetterTile (Node)
├── Background (Node + Sprite)
└── CharLabel (Node + Label)
```

#### 1.3 详细节点配置

**LetterTile根节点:**
- **Transform**: Position(0, 0, 0), Rotation(0, 0, 0), Scale(1, 1, 1)
- **UITransform**: 
  - ContentSize: Width=80, Height=80
  - AnchorPoint: X=0.5, Y=0.5
- **挂载脚本**: `LetterTile.ts`
  - charLabel: 拖拽CharLabel节点
  - bgSprite: 拖拽Background节点的Sprite组件

**Background子节点:**
- **Transform**: Position(0, 0, 0), Rotation(0, 0, 0), Scale(1, 1, 1)
- **UITransform**: 
  - ContentSize: Width=80, Height=80

- **Sprite组件**: 
  - Type: SIMPLE
  - Color: White (255, 255, 255, 255)

**CharLabel子节点:**
- **Transform**: Position(0, 0, 0), Rotation(0, 0, 0), Scale(1, 1, 1)
- **UITransform**: 
  - ContentSize: Width=60, Height=60

  - LineHeight: 32

  - VerticalAlign: CENTER

- **Ctrl+S** 保存预制体

## 第四部分：问题排查指南

### 10. 常见问题和解决方案

#### 问题1: "Unexpected end of JSON input"
**症状**: 预览时控制台报JSON解析错误
**解决步骤**:
1. 检查 `assets/resources/words/words_core.json` 文件是否存在
2. 检查 `assets/resources/words/zh_gloss.json` 文件是否存在  
3. 验证JSON文件格式是否正确
4. 重新导入资源: 右键resources文件夹 > **重新导入资源**

#### 问题2: 瓦片不显示或显示异常
**症状**: 网格中看不到瓦片或布局混乱
**解决步骤**:
1. **检查LetterTile预制体**:
   - 确认预制体文件存在
   - 检查UITransform的ContentSize设置
   - 验证Label和Sprite组件配置

2. **检查GameBoard配置**:
   - 确认tilePrefab引用正确
   - 检查Layout组件设置
   - 验证container引用正确

3. **检查脚本绑定**:
   - GameBoard.ts正确挂载到BoardContainer
   - 所有@property引用都已绑定

#### 问题3: 脚本编译错误
**症状**: 控制台显示TypeScript编译错误
**解决步骤**:
1. **菜单 > 开发者 > 重新编译脚本**
2. **检查TypeScript语法**:
   - 确认所有import路径正确
   - 检查类型定义
   - 验证@property装饰器语法

3. **清理缓存**:
   - 关闭Cocos Creator
   - 删除项目目录下的 `library/` 文件夹
   - 重新打开项目
