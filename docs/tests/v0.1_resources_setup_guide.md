## 二、主要组件资源配置

### 🎯 LetterTile 预制体配置

#### Background节点配置
```
组件：Sprite
├── Type: SIMPLE
├── SpriteFrame: 不设置（代码动态从tiles/加载）
├── Color: #FFFFFF
└── Size Mode: CUSTOM
```

**代码自动加载的资源：**
- `tiles/tile_selectable.png` → selectable状态
- `tiles/tile_highlight.png` → highlight状态  
- `tiles/tile_correct.png` → correct状态
- `tiles/tile_wrong.png` → wrong状态
- `tiles/tile_disabled.png` → disabled状态

### 🎮 HUD 信息按钮配置

#### InfoButton节点配置
```
组件：Button + Sprite
├── Button.Transition: COLOR
├── Sprite.SpriteFrame: 不设置（代码自动加载）
└── 自动加载资源: icons/bulb.png
```

### 🃏 按钮通用配置模板

#### 使用实际按钮素材
```
组件：Button + Sprite
├── Button.Transition: SPRITE (使用精灵切换)
├── Normal Sprite: assets/resources/buttons/btn_primary_default.png
├── Pressed Sprite: assets/resources/buttons/btn_primary_pressed.png  
├── Disabled Sprite: assets/resources/buttons/btn_primary_disabled.png
└── Duration: 0.1
```

**手动设置步骤：**
1. 选中按钮节点
2. **属性检查器** > **Button组件**
3. **Transition** 改为 **SPRITE**
4. 分别拖拽对应状态的图片到相应字段

### 📜 GlossSheet 词义卡配置

#### Panel节点配置
```
组件：Sprite
├── Type: SLICED (9-slice模式)
├── SpriteFrame: 不设置（代码自动加载）
└── 自动加载资源: modal/modal_card_9slice.png
```

#### StarButton节点配置
```
组件：Button + Sprite  
├── Button: 默认配置
├── Sprite.SpriteFrame: 不设置（代码自动加载）
└── 自动加载资源: badges/reward_star.png
```

// ✅ 正确路径
const spritePath = `tiles/tile_${state}`;
resources.load(`${spritePath}/spriteFrame`, SpriteFrame, callback);

## 五、手动配置步骤详解

### 🔧 配置StartButton使用按钮素材

**步骤：**
1. **选中StartButton节点**
2. **属性检查器** > **Button组件**
3. **Transition** 从 `COLOR` 改为 `SPRITE`
4. **Normal Sprite**：
   - 点击右侧圆点按钮
   - 选择 `assets/resources/buttons/btn_primary_default`
5. **Pressed Sprite**：
   - 选择 `assets/resources/buttons/btn_primary_pressed`
6. **Disabled Sprite**：
   - 选择 `assets/resources/buttons/btn_primary_disabled`

### 🔧 配置GlossSheet使用9-slice背景

**步骤：**
1. **选中GlossSheet下的Panel节点**
2. **添加Sprite组件**（如果没有）
3. **属性检查器** > **Sprite组件**
4. **Type** 改为 `SLICED`
5. **SpriteFrame**：
   - 选择 `assets/resources/modal/modal_card_9slice`
6. **Color** 设为 `#FFFFFF`

### 🔧 为InfoButton添加灯泡图标

**代码自动处理，无需手动配置**
```
HUD.ts 会自动加载 icons/bulb.png 并设置到按钮上
```

## 八、常见问题解决

### ❌ 问题1：瓦片显示纯色而非图片
**原因：** 资源路径错误或图片文件缺失
**解决：**
1. 检查 `assets/resources/tiles/` 目录是否包含5个PNG文件
2. 确认文件名正确：`tile_selectable.png` 等
3. 查看控制台是否有加载错误日志

### ❌ 问题2：按钮样式不正确
**原因：** 未正确配置Button组件的Sprite模式
**解决：**
1. 选中按钮节点
2. Button组件 > Transition 改为 `SPRITE`
3. 手动设置Normal/Pressed/Disabled Sprite

### ❌ 问题3：9-slice背景显示异常
**原因：** Sprite组件Type未设为SLICED
**解决：**
1. 选中Panel节点
2. Sprite组件 > Type 改为 `SLICED`
3. 确认SpriteFrame已设置

### ❌ 问题4：图标不显示
**原因：** 节点缺少Sprite组件
**解决：**
1. 选中目标节点
2. 添加Sprite组件
3. 代码会自动设置SpriteFrame
