# W-Game v0.1 游戏玩法指南

## 🎮 游戏概述

W-Game是一款基于Boggle规则的4×4字母网格单词查找游戏。玩家需要在限定时间内，通过连接相邻字母来拼出英文单词。

## 🕹️ 核心玩法

### 基本规则

1. **4×4字母网格**：游戏界面显示16个字母瓦片，排列成4×4网格
2. **连接相邻字母**：点击字母瓦片来连接相邻的字母，形成单词
3. **8方向连接**：可以向上、下、左、右以及4个对角线方向连接
4. **单次使用**：每个字母瓦片在一个单词中只能使用一次
5. **最小长度**：单词长度通常为3-6个字母

### 瓦片状态系统

游戏使用5种瓦片状态，对应`assets/resources/tiles/`下的图片：

| 状态 | 图片文件 | 颜色主题 | 说明 |
|------|----------|----------|------|
| **selectable** | `tile_selectable.png` | 白色 | 可以点击选择的瓦片 |
| **selected** | `tile_selected.png` | 蓝色 | 已被选中的瓦片 |
| **highlight** | `tile_highlight.png` | 金色 | 高亮提示的瓦片 |
| **correct** | `tile_correct.png` | 绿色 | 正确答案的瓦片 |
| **wrong** | `tile_wrong.png` | 红色 | 错误选择的瓦片 |
| **disabled** | `tile_disabled.png` | 灰色 | 不可选择的瓦片 |

### 选择逻辑

1. **初始状态**：所有瓦片为`selectable`（白色）
2. **点击瓦片**：
   - 被点击的瓦片变为`selected`（蓝色）
   - 相邻8个方向的瓦片保持`selectable`（白色）
   - 非相邻的瓦片变为`disabled`（灰色）
3. **继续选择**：只能点击`selectable`状态的瓦片
4. **撤销选择**：点击最后选择的瓦片可以撤销

## 🎯 游戏目标

### 当前版本（v0.1）
- **单个目标词**：每轮游戏有一个隐藏的目标单词
- **时间限制**：60秒倒计时（目前设置为固定值）
- **找到目标词**：按正确顺序连接字母拼出目标单词

### 答案验证
1. **正确答案**：
   - 瓦片变为`correct`状态（绿色）
   - 分数增加10分
   - 词义卡从底部滑入显示单词释义
   - 1.2秒后自动开始下一轮

2. **错误答案**：
   - 瓦片变为`wrong`状态（红色）
   - 分数不变
   - 0.5秒后重置选择，继续当前轮

## 🕐 计时系统

- **初始时间**：60秒（显示为"1:00"）
- **颜色变化**：
  - 60秒→30秒：黑色显示
  - 30秒→10秒：橙色警告
  - ≤10秒：红色闪烁
- **游戏结束**：时间归零自动跳转到结果页面

## 💡 UI功能

### HUD界面
- **左上角**：倒计时器
- **右上角**：当前分数
- **中央**：信息按钮（💡图标），点击显示最近单词的词义

### 词义卡（Bottom Sheet）
- **触发方式**：答对单词或点击信息按钮
- **显示内容**：英文单词 + 中文释义
- **交互功能**：收藏按钮（⭐）、关闭按钮
- **自动隐藏**：1.2秒后自动滑出

### 生词本
- **记录功能**：自动记录本局答对的单词
- **查看位置**：结果页面的滚动列表
- **管理功能**：可清空生词本

## 🎲 网格生成算法

### 目标词嵌入
1. **随机路径**：算法在4×4网格中生成一条可达路径
2. **字母放置**：将目标单词的字母按顺序放置在路径上
3. **填充干扰**：其余位置填充随机字母
4. **路径验证**：确保目标单词可以通过8方向连接找到

### 示例网格
```
假设目标单词是"GAME"：
B  A  Z  S
N  G  A  P  ← G-A路径
L  C  M  M  ← A-M路径  
D  L  E  O  ← M-E路径
```

## 🎮 操作指南

### 基本操作
1. **开始游戏**：从主菜单点击"开始游戏"
2. **选择字母**：点击字母瓦片进行选择
3. **构建路径**：依次点击相邻字母形成单词
4. **撤销操作**：点击路径最后一个字母可撤销
5. **查看词义**：点击💡按钮查看单词释义

### 高级技巧
1. **观察目标**：注意控制台日志会显示目标单词（测试用）
2. **规划路径**：先观察整个网格，寻找可能的单词路径
3. **8方向思维**：记住可以对角线连接
4. **时间管理**：在时间充足时仔细思考，时间紧张时快速尝试

## 🏆 评分系统

### 当前版本
- **正确单词**：+10分
- **错误尝试**：0分（不扣分）
- **时间奖励**：暂无（将来版本可能加入）

### 成就系统（规划中）
- **速度奖励**：快速完成的时间奖励
- **连击奖励**：连续答对的奖励倍数
- **词汇量**：不同长度单词的分数差异
