# W-Game v0.1 测试指南

## 项目概述

W-Game是基于Cocos Creator 3.8.5的单词查找游戏，支持微信小游戏平台。玩家需在4×4字母网格中找到隐藏的英文单词，并可查看中文释义建立生词本。

## 测试前准备

### 环境要求
- Cocos Creator 3.8.5 中文版
- Node.js 环境
- 微信开发者工具（可选，用于小游戏测试）

### 项目结构确认

**核心资源文件**：
```
src/cocos/assets/
├── resources/words/
│   ├── words_core.json          # 英文单词库（按长度3-6分组）
│   └── zh_gloss.json            # 中英文对照词典
├── ui/
│   ├── tiles/                   # 瓦片状态图片资源
│   │   ├── tile_selectable.png
│   │   ├── tile_highlight.png
│   │   ├── tile_correct.png
│   │   ├── tile_wrong.png
│   │   └── tile_disabled.png
│   ├── buttons/                 # 按钮样式资源
│   ├── icons/                   # 图标资源
│   └── LetterTile.prefab       # 字母瓦片预制体
└── scripts/
    ├── data/
    │   ├── GlossService.ts     # 词库服务
    │   └── WordBank.ts         # 词库管理
    ├── ui/
    │   ├── LetterTile.ts       # 字母瓦片组件
    │   ├── GameBoard.ts        # 游戏棋盘组件
    │   ├── GlossSheet.ts       # 词义卡片组件
    │   └── HUD.ts              # 游戏界面HUD组件
    ├── app/
    │   ├── MainMenu.ts         # 主菜单控制器
    │   ├── GameApp.ts          # 游戏主控制器
    │   └── ResultPage.ts       # 结果页面控制器
    └── util/
        └── AudioMgr.ts         # 音频管理器
```

## 场景配置

### 1. MainMenu场景
```
MainMenuCanvas (Canvas)
├── TitleLabel (Label) - "Word Game"
├── StartButton (Button) - "开始游戏"
└── SettingsPanel (Node)
    └── UseFullToggle (Toggle) - "使用完整词库"
```

**脚本绑定**：MainMenu.ts → MainMenuCanvas

### 2. Game场景
```
GameCanvas (Canvas)
├── HUD (Node)
│   ├── TimerLabel (Label) - 显示倒计时
│   ├── ScoreLabel (Label) - 显示分数
│   └── InfoButton (Button) - 信息按钮
├── BoardContainer (Node) - 4×4网格容器
└── GlossSheet (Node) - 词义卡片
    └── Panel (Node)
        ├── TitleLabel (Label) - 单词标题
        ├── DescLabel (Label) - 中文释义
        ├── StarButton (Button) - 收藏按钮
        └── CloseButton (Button) - 关闭按钮
```

**脚本绑定**：
- GameApp.ts → GameCanvas
- HUD.ts → HUD节点
- GlossSheet.ts → GlossSheet节点
- GameBoard.ts → BoardContainer节点

### 3. Result场景
```
ResultCanvas (Canvas)
├── TitleLabel (Label) - "游戏结果"
├── StatisticsLabel (Label) - 统计信息
├── NotebookScrollView (ScrollView)
│   └── Content (Node) - 生词本内容容器
├── ClearButton (Button) - "清空生词本"
└── ReturnButton (Button) - "返回主菜单"
```

**脚本绑定**：ResultPage.ts → ResultCanvas

### 4. LetterTile预制体
```
LetterTile (Node)
├── Background (Sprite) - 背景图片组件
└── CharLabel (Label) - 字母显示组件
```

**脚本绑定**：LetterTile.ts → LetterTile根节点

- ✅ 所有位置都有字母显示

#### 测试4：选择交互逻辑
**目标**：验证瓦片选择和状态变化逻辑

**步骤**：
1. 点击任意瓦片
2. 观察该瓦片和周围瓦片的状态变化
3. 继续点击相邻瓦片
4. 尝试点击非相邻瓦片

**预期结果**：
- 被点击瓦片：变为"selected"状态（蓝色）
- 相邻瓦片（8方向）：变为"selectable"状态（白色）
- 非相邻瓦片：变为"disabled"状态（灰色）

**验收标准**：
- ✅ 瓦片状态正确切换
- ✅ 8方向相邻逻辑正确
- ✅ 点击非相邻瓦片无响应

## 常见问题排查

### 问题1：词库加载失败
**症状**：控制台显示词库加载错误，游戏无法开始
**排查步骤**：
1. 检查`words_core.json`和`zh_gloss.json`文件是否存在
2. 验证JSON格式是否正确
3. 检查resources目录配置
4. 查看资源加载路径是否正确

### 问题2：瓦片不显示或显示异常
**症状**：瓦片不显示、显示纯色或布局混乱
**排查步骤**：
1. 检查LetterTile预制体配置
2. 验证瓦片图片资源是否存在
3. 检查GameBoard的Layout组件设置
4. 确认脚本正确绑定到节点

### 问题3：场景跳转失败
**症状**：点击按钮无反应或场景切换报错
**排查步骤**：
1. 检查场景文件是否添加到构建设置
2. 验证场景名称拼写正确
3. 检查按钮事件绑定
4. 查看director.loadScene的错误回调

### 问题4：触摸事件无响应
**症状**：点击瓦片无反应
**排查步骤**：
1. 检查节点的触摸事件是否正确设置
2. 验证节点层级关系
3. 确认UITransform组件存在
4. 检查是否有遮挡的透明节点
