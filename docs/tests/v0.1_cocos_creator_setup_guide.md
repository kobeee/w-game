# W-Game v0.1 Cocos Creator 3.8.7 详细配置指南

## 项目概述

本指南详细说明如何在Cocos Creator 3.8.7中文版中配置W-Game项目的每个场景、节点和组件。

---

## 第一部分：项目基础配置

### 1. 项目设置

#### 1.1 项目数据
1. **菜单栏** > **项目** > **项目设置**
2. **项目数据**选项卡：
   - **设计分辨率**：宽度=750, 高度=1334
   - **适配屏幕宽度**：勾选 ✓
   - **适配屏幕高度**：不勾选 ✗
   - **方向**：Portrait (竖屏)

#### 1.2 构建设置  
1. **菜单栏** > **项目** > **构建发布**
2. **发布平台**：Web Mobile
3. **场景列表**：依次添加 MainMenu、Game、Result
4. **起始场景**：MainMenu

## 第二部分：实际资源使用说明

### 💎 美术素材总览

W-Game项目包含丰富的美术素材，位于 `assets/resources/` 目录：

#### 🎯 核心游戏素材
```

├── tile_selectable.png   # 可选择状态（白色主题）
├── tile_highlight.png    # 高亮状态（金色主题）
├── tile_correct.png      # 正确状态（绿色主题）
├── tile_wrong.png        # 错误状态（红色主题）
└── tile_disabled.png     # 禁用状态（灰色主题）

buttons/                   # ⭐ 按钮3种状态图片（9-slice）
├── btn_primary_default.png   # 按钮默认状态
├── btn_primary_pressed.png   # 按钮按下状态
└── btn_primary_disabled.png  # 按钮禁用状态

icons/                     # ⭐ 功能图标
├── bulb.png              # 信息按钮灯泡图标
├── pause.png             # 暂停图标
├── settings.png          # 设置图标
├── sound_on.png          # 音效开启
├── sound_off.png         # 音效关闭
└── shuffle.png           # 洗牌图标

modal/                     # ⭐ 弹窗素材（9-slice）
├── modal_card_9slice.png  # 词义卡背景
└── overlay.png           # 半透明遮罩

badges/                    # ⭐ 奖励徽章

```

#### 🎨 装饰素材（可选使用）
```
bg/                        # 背景图片

pets/                      # 🐾 萌宠表情（将来版本使用）
```

### 🔄 代码自动加载资源

以下资源由代码自动加载，**无需手动设置**：

| 组件 | 自动加载的资源 | 降级方案 |
|------|-------------|---------|
| LetterTile.ts | tiles/tile_*.png (5个状态图片) | 纯色显示 |
| HUD.ts | icons/bulb.png (信息按钮图标) | 文字显示 |
| GlossSheet.ts | modal/modal_card_9slice.png (弹窗背景) | 纯色背景 |
| GlossSheet.ts | badges/reward_star.png (收藏图标) | 文字显示 |

### 🔧 手动配置资源

以下资源需要在编辑器中**手动拖拽设置**：

| 节点 | 推荐使用的资源 | 配置位置 |
|------|-------------|---------|
| StartButton | buttons/btn_primary_*.png | Button组件 > Sprite模式 |
| 所有Button | buttons/btn_primary_*.png | Button组件 > Sprite模式 |
| MainMenu背景 | bg/main_bg_flat_C_dither.png | Canvas下Background节点 |

### 📋 手动配置按钮素材的详细步骤

对于所有Button节点（StartButton、ClearButton、ReturnButton等），推荐使用实际按钮图片：

**步骤：**
1. **选中任意Button节点**
2. **属性检查器** > **Button组件**
3. **Transition** 从 `COLOR` 改为 `SPRITE`
4. **Normal Sprite**：
   - 点击右侧圆点按钮
   - 选择 `assets/resources/buttons/btn_primary_default`
5. **Pressed Sprite**：
   - 选择 `assets/resources/buttons/btn_primary_pressed`
6. **Disabled Sprite**：
   - 选择 `assets/resources/buttons/btn_primary_disabled`
7. **属性检查器** > **Sprite组件**
8. **Type** 改为 `SLICED` (支持9-slice自适应尺寸)

**效果对比：**
- ❌ **COLOR模式**：纯色按钮，交互时只改变颜色
- ✅ **SPRITE模式**：精美按钮图片，交互时切换不同状态图片

## 第三部分：预制体创建

### 2. LetterTile 预制体配置

#### 2.1 创建预制体
1. **资源管理器** > **右键** > **创建** > **预制体**
2. **重命名**：`LetterTile`
3. **双击**打开预制体编辑器

#### 2.2 节点层级结构
```
LetterTile (空节点)
├── Background (空节点 + Sprite精灵组件)  
└── CharLabel (空节点 + Label文本组件)
```

#### 2.3 LetterTile根节点配置
1. **选中LetterTile根节点**
2. **属性检查器**配置：

**变换组件 (Transform)：**
- 位置：X=0, Y=0, Z=0
- 旋转：X=0, Y=0, Z=0
- 缩放：X=1, Y=1, Z=1

**UI变换组件 (UITransform)：**
- 尺寸类型：自定义
- 内容尺寸：宽度=80, 高度=80
- 锚点：X=0.5, Y=0.5

**脚本组件：**
3. **添加组件** > **自定义脚本** > 选择 `LetterTile`
4. **脚本属性绑定**：
   - **Char Label**：拖拽 CharLabel 节点到此字段
   - **Bg Sprite**：拖拽 Background 节点到此字段

#### 2.4 Background子节点配置
1. **选中LetterTile** > **右键** > **创建** > **创建2D对象** > **Sprite精灵**
2. **重命名**为 `Background`
3. **属性检查器**配置：

**变换组件 (Transform)：**
- 位置：X=0, Y=0, Z=0
- 旋转：X=0, Y=0, Z=0  
- 缩放：X=1, Y=1, Z=1

**UI变换组件 (UITransform)：**
- 内容尺寸：宽度=80, 高度=80
- 锚点：X=0.5, Y=0.5

**精灵组件 (Sprite)：**
- 类型：Simple
- 精灵图集：暂不设置（代码从 `assets/resources/tiles/` 动态加载）
- 颜色：#FFFFFF (白色)
- 不透明度：255
- **重要说明**：LetterTile.ts会自动加载以下5个状态图片：
  - `tiles/tile_selectable.png` - 可选择状态（白色）
  - `tiles/tile_highlight.png` - 高亮状态（金色）
  - `tiles/tile_correct.png` - 正确状态（绿色）
  - `tiles/tile_wrong.png` - 错误状态（红色）
  - `tiles/tile_disabled.png` - 禁用状态（灰色）

#### 2.5 CharLabel子节点配置
1. **选中LetterTile** > **右键** > **创建** > **创建2D对象** > **Label文本**
2. **重命名**为 `CharLabel`
3. **属性检查器**配置：

**变换组件 (Transform)：**
- 位置：X=0, Y=0, Z=0
- 旋转：X=0, Y=0, Z=0
- 缩放：X=1, Y=1, Z=1

**UI变换组件 (UITransform)：**
- 内容尺寸：宽度=60, 高度=60
- 锚点：X=0.5, Y=0.5

**文本组件 (Label)：**
- 字符串：A
- 字体：默认字体
- 字体大小：32
- 行高：32
- 颜色：#404040 (深灰色，保证在不同背景色上的可见性)
- 溢出处理：截断
- 水平对齐：居中
- 垂直对齐：居中
- 启用粗体：否
- 启用斜体：否
- 启用下划线：否

#### 2.6 保存预制体
- **Ctrl+S** 保存预制体
- **关闭预制体编辑器**

## 第七部分：常见问题排查

### 8. 问题诊断指南

#### 问题1：预制体不显示
**症状**：网格中看不到字母瓦片
**排查步骤**：
1. **检查预制体路径**：确认LetterTile.prefab存在
2. **检查GameBoard脚本**：tilePrefab字段是否正确绑定
3. **检查Layout组件**：约束类型=FIXED_COL，约束数量=4
4. **检查UITransform**：container尺寸是否合适

#### 问题2：Widget对齐不生效
**症状**：节点位置不正确
**排查步骤**：
1. **检查Widget组件**：是否正确添加到节点
2. **检查父节点**：确认父节点有UITransform组件
3. **检查对齐模式**：TOP/BOTTOM/CENTER/LEFT/RIGHT设置
4. **手动调用**：代码中调用widget.updateAlignment()

#### 问题3：脚本属性绑定失败
**症状**：属性字段显示为None或空
**排查步骤**：
1. **检查节点存在**：确认目标节点已创建
2. **检查组件类型**：Label字段绑定Label组件，Button字段绑定Button组件
3. **重新绑定**：删除绑定后重新拖拽节点
4. **检查脚本编译**：确认TypeScript脚本无报错

#### 问题4：颜色显示异常
**症状**：颜色与设计不符
**排查步骤**：
1. **检查十六进制格式**：确保格式为#RRGGBB
2. **检查组件类型**：Sprite用color属性，Label用color属性
3. **检查透明度**：Sprite的不透明度设置
4. **检查代码覆盖**：脚本中是否有颜色设置覆盖UI配置
