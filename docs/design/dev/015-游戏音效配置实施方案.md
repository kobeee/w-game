# 游戏音效配置实施方案

**文档编号**：015  
**创建日期**：2025-12-01  
**状态**：拟定  
**适用版本**：v0.1 (MVP)

## 1. 背景与目的

项目已进入 v0.1 开发尾声，核心玩法逻辑已完成。当前音频管理模块 (`AudioMgr.ts`) 虽然已实现，但缺少实际的音频资源文件。本方案旨在明确 v0.1 版本所需的音效清单、资源规范及获取渠道，指导后续的资源导入工作，以提升游戏的听觉反馈和整体完成度。

## 2. 音频资源需求清单

根据 `AudioMgr.ts` 代码逻辑及产品需求文档（PRD），以下为必须配置的音频资源。

### 2.1. 核心基础音效 (必需)

这些音效在代码中已被硬编码引用，缺失将导致控制台警告或逻辑报错。

| 键名 (Key) | 建议文件名 | 类型 | 触发场景 | 建议听感 |
| :--- | :--- | :--- | :--- | :--- |
| **bg_music** | `background.mp3` | Music | 游戏主场景循环播放 | 轻松、休闲、愉悦、不抢戏的 Loop 音乐 |
| **click** | `click.mp3` | SFX | 点击通用按钮 | 短促、清脆的机械或气泡声 |
| **correct** | `correct.mp3` | SFX | 单词拼写正确提交 | 积极、上扬的叮咚声或和弦 |
| **wrong** | `wrong.mp3` | SFX | 单词拼写错误提交 | 低沉、短促的蜂鸣或错误提示音 |
| **tick** | `tick.mp3` | SFX | 倒计时警报/字母选中 | 像时钟走动的滴答声或木鱼声 |

## 3. 资源技术规范

为确在保微信小游戏环境下的加载速度和兼容性，请遵循以下规范：

*   **背景音乐 (Music)**:
    *   格式：**MP3** (推荐) 或 AAC。
    *   比特率：96kbps - 128kbps (平衡体积与音质)。
    *   声道：立体声 (Stereo)。
    *   加载方式：在 Cocos 属性检查器中设置为 `DOM Audio` (小游戏平台可能自动处理，建议默认)。
*   **音效 (SFX)**:
    *   格式：**MP3** 或 **WAV** (短音效 WAV 解码快，MP3 体积小)。
    *   时长：通常 < 1秒。
    *   声道：单声道 (Mono) 以节省体积，除非有特殊方位需求。
    *   加载方式：默认。

## 4. 目录结构规划

请严格按照以下目录结构存放文件，以匹配代码中的 `resources.load` 路径：

```text
src/cocos/assets/resources/
└── audio/
    ├── music/
    │   └── background.mp3      <-- 对应 path: 'audio/music/background'
    └── sfx/
        ├── click.mp3           <-- 对应 path: 'audio/sfx/click'
        ├── correct.mp3         <-- 对应 path: 'audio/sfx/correct'
        ├── wrong.mp3           <-- 对应 path: 'audio/sfx/wrong'
        └── tick.mp3            <-- 对应 path: 'audio/sfx/tick'
```

### 5.3. 生成参数建议

- **采样率**：44100 Hz
- **比特率**：128kbps (MP3格式)
- **声道**：单声道 (节省文件大小)
- **格式**：MP3 (兼容微信小游戏)
- **音量标准化**：-6dB (避免过载)

## 6. 实施步骤

1.  **生成音效**：使用上述提示词在 Stable Audio Open 中生成对应音效
2.  **后期处理**：使用音频编辑软件调整音量、裁剪时长
3.  **格式转换**：确保所有音效为 MP3 格式，符合技术规范
4.  **重命名**：按照 §2 中的"建议文件名"进行重命名
5.  **导入项目**：将文件放入 `src/cocos/assets/resources/audio/` 对应目录
6.  **Cocos 设置**：
    *   检查音频文件的导入设置
    *   `background.mp3` 设置为 `Dom Audio`
7.  **测试验证**：运行游戏，确认所有音效正常播放，无控制台警告

## 7. 推荐资源获取渠道 (备用方案)

如果 Stable Audio Open 效果不理想，可使用以下免费资源：

1.  **UI & 操作音效 (Click, Tick, Pop)**
    *   来源：[Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)
    *   推荐文件：`Audio/click_*.ogg`, `Audio/switch_*.ogg`, `Audio/confirmation_*.ogg`

2.  **游戏反馈音效 (Correct, Wrong)**
    *   来源：[Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) 或 [General Sounds](https://kenney.nl/assets/general-sounds)
    *   推荐文件：`Audio/impactBell_heavy_*.ogg` (Correct), `Audio/impactTin_medium_*.ogg` (Wrong)

3.  **背景音乐**
    *   来源：[Kenney Music Jingles](https://kenney.nl/assets/music-jingles)
    *   注意：需选择支持 Loop (循环) 的曲目。
