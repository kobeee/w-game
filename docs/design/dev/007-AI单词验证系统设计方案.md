## 1. 问题背景

### 1.1 核心矛盾

在"字母叠叠乐"玩法中，由于牌堆中的字母是从多个单词打散后随机组合的，会产生大量**有效但不在本地词库**的单词组合。

#### 问题示例

```
关卡选择的目标单词: ["CAT", "DOG", "PIG"]
打散后的字母池: [C, A, T, D, O, G, P, I, G]

玩家可能组合出的有效单词:
✅ CAT (在词库) → 消除成功
✅ DOG (在词库) → 消除成功
❌ PIG (在词库) → 消除成功
❌ COD (鳕鱼，不在词库) → 拒绝消除 ← 用户困惑！
❌ GAP (间隙，不在词库) → 拒绝消除 ← 用户困惑！
❌ POD (豆荚，不在词库) → 拒绝消除 ← 用户困惑！
```

### 1.2 问题严重性评估

| 单词长度 | 英语全词库数量 | 当前词库数量 | 覆盖率 | 用户受挫概率 |
|---------|--------------|-------------|--------|-------------|
| 3字母 | ~1,000 | 500 | 50% | **极高（50%）** |
| 4字母 | ~5,000 | 800 | 16% | **极高（84%）** |
| 5字母 | ~10,000 | 1,200 | 12% | **极高（88%）** |
| 6+字母 | ~50,000 | 2,000 | 4% | **极高（96%）** |

**关键结论**：
- 即使扩充到 10,000 词，仍有大量有效单词被拒绝
- 词库维护成本高，永远无法达到 100% 覆盖
- **用户体验致命伤**："这明明是单词，为什么不能消除？"

## 2. 核心解决方案

### 2.1 方案概述

使用 **Google Gemini AI** 实时验证单词有效性，实现：
- ✅ **近乎 100% 覆盖率**：包括生僻词、俚语、专有名词
- ✅ **实时中文释义**：验证通过时自动返回中文解释
- ✅ **极低延迟**：200-400ms 响应时间，用户无感知
- ✅ **免维护**：无需手工扩充词库

### 2.2 三层验证策略

```
用户点击字母 → 字母飞向牌槽（0.4s动画）
    │
    ├─→ [并发执行] 单词验证流程
    │    │
    │    ├─→ 第1层：本地词库（5500词，<10ms）     命中率 80%
    │    │    └─→ 核心词库500词 + 扩展词库5000词
    │    │
    │    ├─→ 第2层：全局单词缓存/Redis（<5ms）    命中率 +19% = 99%
    │    │    └─→ 跨用户共享，自然增长，永久缓存
    │    │
    │    └─→ 第3层：Gemini API（200-400ms）       命中率 +1% = 100%
    │         └─→ 验证后自动存入Redis缓存
    │
    └─→ [等待] 飞行动画完成
         │
         └─→ 卡片落入牌槽
              │
              ├─→ [快速路径] 验证已完成（99%概率）

              │
              └─→ [慢速路径] 验证未完成（1%概率）
                   └─→ 显示"验证中"图标，等待API返回（最多200ms）
                        └─→ 返回后立即触发闪烁
```

**用户体验保证**：

### 5.2 第1层：本地词库（Core + Extended Dictionary）

```typescript
// LocalDictionary.ts - 本地词库管理器

interface DictEntry {
    term: string;         // "CAT"
    cn: string;           // "猫"
}

export class LocalDictionary {
    private coreDict: Map<string, string>;      // 核心词库 500词
    private extendedDict: Set<string>;          // 扩展词库 5000词（仅单词，无释义）

    constructor() {
        this.loadCoreDict();      // 加载 resources/words/words_core.json
        this.loadExtendedDict();  // 加载 resources/words/words_extended.json
    }

    /**
     * 查询单词（核心词库有释义，扩展词库仅验证有效性）
     */
    get(word: string): { valid: boolean; definition?: string } {
        const upperWord = word.toUpperCase();

        // 优先检查核心词库（有释义）
        if (this.coreDict.has(upperWord)) {
            return {
                valid: true,
                definition: this.coreDict.get(upperWord)!
            };
        }

        // 检查扩展词库（无释义，需后续从API获取）
        if (this.extendedDict.has(upperWord)) {
            return {
                valid: true,
                definition: undefined  // 扩展词库无中文释义
            };
        }

        return { valid: false };
    }

    private loadCoreDict() {
        // 加载核心词库（500个高频词，包含中文释义）
        resources.load('words/words_core', JsonAsset, (err, asset) => {
            if (!err) {
                const entries: DictEntry[] = asset.json;
                this.coreDict = new Map(entries.map(e => [e.term, e.cn]));
            }
        });
    }

    private loadExtendedDict() {
        // 加载扩展词库（5000个常用词，仅单词列表）
        resources.load('words/words_extended', JsonAsset, (err, asset) => {
            if (!err) {
                const words: string[] = asset.json;
                this.extendedDict = new Set(words);
            }
        });
    }
}

### 5.3 第2层：全局单词缓存（Redis Global Cache）

```python
# backend/word_validator.py - Redis全局单词缓存

import redis
import json
from typing import Optional

# Redis客户端（跨用户共享）
redis_client = redis.Redis(
    host='localhost',
    port=6379,
    db=0,
    decode_responses=True
)

# 缓存配置
WORD_CACHE_PREFIX = "word:"
WORD_CACHE_TTL = 86400 * 365  # 1年过期（单词定义基本不变）

def get_word_from_cache(word: str) -> Optional[dict]:
    """从全局缓存获取单词验证结果"""
    cache_key = f"{WORD_CACHE_PREFIX}{word.upper()}"
    cached = redis_client.get(cache_key)
    if cached:
        return json.loads(cached)
    return None

def save_word_to_cache(word: str, result: dict):
    """保存单词验证结果到全局缓存"""
    cache_key = f"{WORD_CACHE_PREFIX}{word.upper()}"
    redis_client.setex(
        cache_key,
        WORD_CACHE_TTL,
        json.dumps(result)
    )

@app.post("/api/validate-word")
async def validate_word(request: ValidateRequest):
    word = request.word.strip().upper()

    # 检查全局单词缓存（命中率约19%，运行1个月后）
    cached_result = get_word_from_cache(word)
    if cached_result:
        print(f"[Cache] ✅ 全局单词缓存命中: {word}")
        return ValidateResponse(**cached_result, source="redis")

    # 缓存未命中，继续调用Gemini API（第3层）
    result = await call_gemini_api(word)

    # 验证通过后，自动存入全局缓存
    if result['valid']:
        save_word_to_cache(word, result)

    return ValidateResponse(**result, source="gemini")
```

### 5.4 第3层：Gemini API（AI Validation）

```typescript
// GeminiAPIService.ts - Gemini API调用服务

// 触发条件: 本地词库和Redis缓存都未命中（约1%概率）
// 命中延迟: 200-400ms
// 累计命中率: 100%

class GeminiAPIService {
    private readonly API_URL = 'https://your-backend.com/api/validate-word';
    private cache: Map<string, ValidateResult> = new Map();
    private rateLimiter: RateLimiter;

    async validate(word: string): Promise<ValidateResult> {
        // 1. 检查缓存
        if (this.cache.has(word)) {
            return this.cache.get(word)!;
        }

        // 2. 限流检查
        if (!await this.rateLimiter.checkLimit()) {
            throw new Error('API_RATE_LIMIT_EXCEEDED');
        }

        // 3. 调用后端API
        const result = await this.callBackendAPI(word);

        // 4. 缓存结果
        if (result.valid) {
            this.cache.set(word, result);
        }

        return result;
    }

    private async callBackendAPI(word: string): Promise<ValidateResult> {
        return new Promise((resolve, reject) => {
            const timeout = setTimeout(() => reject(new Error('API_TIMEOUT')), 1500);

            if (sys.platform === sys.Platform.WECHAT_GAME) {
                wx.request({
                    url: this.API_URL,
                    method: 'POST',
                    header: { 'content-type': 'application/json' },
                    data: { word },
                    success: (res) => {
                        clearTimeout(timeout);
                        resolve(res.data as ValidateResult);
                    },
                    fail: (err) => {
                        clearTimeout(timeout);
                        reject(err);
                    }
                });
            } else {
                // Cocos 预览模式
                fetch(this.API_URL, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ word })
                })
                    .then(res => res.json())
                    .then(data => {
                        clearTimeout(timeout);
                        resolve(data);
                    })
                    .catch(err => {
                        clearTimeout(timeout);
                        reject(err);
                    });
            }
        });
    }
}
```

### 5.5 混合验证器（Hybrid Validator）

```typescript
// HybridWordValidator.ts - 三层验证统一入口

interface ValidateResult {
    valid: boolean;
    definition?: string;
    source: 'local' | 'redis' | 'gemini' | 'offline';
    latency?: number; // 调试用
}

export class HybridWordValidator {
    private localDict: LocalDictionary;
    private geminiAPI: GeminiAPIService;

    constructor() {
        this.localDict = new LocalDictionary();
        this.geminiAPI = new GeminiAPIService();
    }

    async validate(word: string): Promise<ValidateResult> {
        const startTime = Date.now();
        word = word.toUpperCase();

        // 第1层：本地词库（核心+扩展）
        const localResult = this.localDict.get(word);
        if (localResult.valid) {
            return {
                ...localResult,
                source: 'local',
                latency: Date.now() - startTime
            };
        }

        // 第2+3层：调用后端API（自动检查Redis缓存 + Gemini API）
        try {
            const apiResult = await this.geminiAPI.validate(word);
            return {
                ...apiResult,
                // source由后端返回: 'redis' 或 'gemini'
                latency: Date.now() - startTime
            };
        } catch (error) {
            console.error(`[Validator] API验证失败: ${word}`, error);
            // 降级：网络异常时返回无效
            return {
                valid: false,
                source: 'offline',
                latency: Date.now() - startTime
            };
        }
    }

// NetworkService.ts - 微信小游戏网络请求封装

import { sys } from 'cc';

export class NetworkService {
    private static readonly BASE_URL = 'https://your-backend.com';

    static async post<T>(endpoint: string, data: any, timeout: number = 2000): Promise<T> {
        return new Promise((resolve, reject) => {
            const timer = setTimeout(() => reject(new Error('TIMEOUT')), timeout);

            if (sys.platform === sys.Platform.WECHAT_GAME) {
                // 微信小游戏平台
                wx.request({
                    url: `${this.BASE_URL}${endpoint}`,
                    method: 'POST',
                    header: { 'content-type': 'application/json' },
                    data,
                    timeout,
                    success: (res) => {
                        clearTimeout(timer);
                        if (res.statusCode === 200) {
                            resolve(res.data as T);
                        } else {
                            reject(new Error(`HTTP_${res.statusCode}`));
                        }
                    },
                    fail: (err) => {
                        clearTimeout(timer);
                        reject(err);
                    }
                });
            } else {
                // Cocos Creator 预览模式
                fetch(`${this.BASE_URL}${endpoint}`, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify(data)
                })
                    .then(res => {
                        if (!res.ok) throw new Error(`HTTP_${res.status}`);
                        return res.json();
                    })
                    .then(data => {
                        clearTimeout(timer);
                        resolve(data as T);
                    })
                    .catch(err => {
                        clearTimeout(timer);
                        reject(err);
                    });
            }
        });
    }
}

### 6.2 后端代理服务（Python FastAPI）

#### 完整代码实现

```python
# backend/word_validator.py
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
import os
import httpx
import json
from typing import Optional

app = FastAPI(title="Word Validator Service", version="1.0.0")

# 允许微信小游戏跨域请求
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产环境改为具体域名
    allow_methods=["POST", "OPTIONS"],
    allow_headers=["*"],
)

# 环境变量读取 API Key
GEMINI_API_KEY = os.getenv("GEMINI_API_KEY")
if not GEMINI_API_KEY:
    raise RuntimeError("GEMINI_API_KEY 环境变量未设置")

GEMINI_ENDPOINT = "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-lite:generateContent"

# 请求体模型
class ValidateRequest(BaseModel):
    word: str

# 响应体模型
class ValidateResponse(BaseModel):
    valid: bool
    definition: Optional[str] = None
    source: str = "gemini"
    error: Optional[str] = None

@app.post("/api/validate-word", response_model=ValidateResponse)
async def validate_word(request: ValidateRequest):
    """
    单词验证接口
    接收: {"word": "CAT"}
    返回: {"valid": true, "definition": "猫", "source": "gemini"}
    """
    word = request.word.strip().upper()

    # 输入验证
    if not word or len(word) < 2 or len(word) > 20:
        return ValidateResponse(valid=False, error="INVALID_INPUT")

    if not word.isalpha():
        return ValidateResponse(valid=False, error="NON_ALPHA_CHARACTERS")

    # 构造 Gemini Prompt
    prompt = f'''判断"{word}"是否是有效的英语单词（包括俚语、专有名词）。
如果是，用20字以内的中文解释其含义。
仅返回JSON格式: {{"valid": true/false, "definition": "释义"}}'''

    try:
        async with httpx.AsyncClient(timeout=3.0) as client:
            response = await client.post(
                GEMINI_ENDPOINT,
                headers={
                    "x-goog-api-key": GEMINI_API_KEY,
                    "Content-Type": "application/json"
                },
                json={
                    "contents": [{
                        "parts": [{"text": prompt}]
                    }],
                    "generationConfig": {
                        "temperature": 0.1,  # 降低随机性
                        "maxOutputTokens": 100,
                        "candidateCount": 1
                    }
                }
            )

            response.raise_for_status()
            result = response.json()

            # 解析 Gemini 返回
            text = result["candidates"][0]["content"]["parts"][0]["text"]

            # 提取 JSON（可能包含 markdown 代码块）
            if "```json" in text:
                text = text.split("```json")[1].split("```")[0].strip()
            elif "```" in text:
                text = text.split("```")[1].split("```")[0].strip()

            parsed = json.loads(text.strip())

            return ValidateResponse(
                valid=parsed.get("valid", False),
                definition=parsed.get("definition", ""),
                source="gemini"
            )

    except httpx.TimeoutException:
        return ValidateResponse(valid=False, error="GEMINI_TIMEOUT")
    except httpx.HTTPStatusError as e:
        return ValidateResponse(valid=False, error=f"GEMINI_HTTP_{e.response.status_code}")
    except (KeyError, json.JSONDecodeError) as e:
        print(f"解析 Gemini 返回失败: {e}")
        return ValidateResponse(valid=False, error="GEMINI_PARSE_ERROR")
    except Exception as e:
        print(f"未知错误: {e}")
        return ValidateResponse(valid=False, error="INTERNAL_ERROR")

@app.get("/health")
async def health_check():
    """健康检查接口"""
    return {"status": "ok", "service": "word-validator"}

# 启动命令

```

## 8. 飞行动画并发优化

### 8.1 核心设计思路

**目标**：在卡片飞行过程中（0.4s）并发执行单词验证，使卡片落地时验证已完成。

**关键挑战**：
- 验证可能快于动画（本地词库 5ms）
- 验证可能慢于动画（API 调用 400ms）
- 需要优雅处理两种情况

### 8.2 状态机设计

```typescript
// 验证状态枚举
enum ValidationState {
    IDLE = 'idle',           // 空闲
    VALIDATING = 'validating', // 验证中
    COMPLETED = 'completed',  // 验证完成
    TIMEOUT = 'timeout'       // 超时
}

interface PendingValidation {
    word: string;
    state: ValidationState;
    result: ValidateResult | null;
}
```

### 8.3 SlotQueue 改造实现

```typescript
// SlotQueue.ts - 飞行动画并发验证

import { tween, Vec3 } from 'cc';
import { HybridWordValidator, ValidateResult } from './HybridWordValidator';

export class SlotQueue extends Component {
    @property(Node)
    loadingIndicator: Node = null!; // "验证中..."图标

    private validator: HybridWordValidator = new HybridWordValidator();
    private pendingValidation: PendingValidation = {
        word: '',
        state: ValidationState.IDLE,
        result: null
    };

    async onCardClick(card: LetterCard) {
        console.log(`[SlotQueue] 卡片点击: ${card.letter}`);

        // ========== 1. 立即开始飞行动画（0.4秒） ==========
        const targetPos = this.getNextSlotPosition();
        const flyPromise = this.animateFlyToSlot(card, targetPos);

        // ========== 2. 并发执行单词验证 ==========
        const letters = [...this.currentLetters, card.letter];
        const word = letters.join('').toUpperCase();

        this.pendingValidation = {
            word,
            state: ValidationState.VALIDATING,
            result: null
        };

        // 并发调用验证器
        const validatePromise = this.validator.validate(word).then(result => {
            console.log(`[Validator] 验证完成: ${word} → ${result.valid}, 延迟${result.latency}ms`);
            this.pendingValidation.state = ValidationState.COMPLETED;
            this.pendingValidation.result = result;
            return result;
        }).catch(error => {
            console.error(`[Validator] 验证失败: ${word}`, error);
            this.pendingValidation.state = ValidationState.TIMEOUT;
            this.pendingValidation.result = { valid: false, source: 'none' };
        });

        // ========== 3. 等待飞行动画完成 ==========
        await flyPromise;

        // ========== 4. 将卡片添加到牌槽 ==========
        this.currentLetters.push(card.letter);
        this.updateSlotDisplay();

        // ========== 5. 判断验证状态 ==========
        if (this.pendingValidation.state === ValidationState.VALIDATING) {
            // 5a. 验证未完成，显示 loading 图标
            console.log(`[SlotQueue] 验证未完成，显示loading...`);
            this.showLoadingIndicator();

            // 等待验证完成（最多再等 500ms）
            const timeoutPromise = new Promise(resolve => setTimeout(resolve, 500));
            await Promise.race([validatePromise, timeoutPromise]);

            this.hideLoadingIndicator();
        }

        // ========== 6. 执行匹配逻辑 ==========
        const result = this.pendingValidation.result;
        if (result && result.valid) {
            console.log(`[SlotQueue] 匹配成功: ${word} → ${result.definition}`);
            // 立即触发闪烁动画（3秒倒计时）
            await this.startBlinkAnimation(word, result.definition || '');

            // 保存到用户历史
            this.validator.onWordMatched(word, result.definition || '');
        }

        // ========== 7. 重置验证状态 ==========
        this.pendingValidation = {
            word: '',
            state: ValidationState.IDLE,
            result: null
        };
    }

    /**
     * 飞行动画（贝塞尔曲线）
     */
    private animateFlyToSlot(card: LetterCard, targetPos: Vec3): Promise<void> {
        return new Promise(resolve => {
            const startPos = card.node.getPosition();
            const controlPoint = new Vec3(
                (startPos.x + targetPos.x) / 2,
                startPos.y + 150, // 抛物线高度
                0
            );

            tween(card.node)
                .to(0.4, { position: targetPos }, {
                    easing: 'sineOut',
                    onUpdate: (target: Node, ratio: number) => {
                        // 贝塞尔曲线路径
                        const t = ratio;
                        const x = (1 - t) * (1 - t) * startPos.x +
                                  2 * (1 - t) * t * controlPoint.x +
                                  t * t * targetPos.x;
                        const y = (1 - t) * (1 - t) * startPos.y +
                                  2 * (1 - t) * t * controlPoint.y +
                                  t * t * targetPos.y;
                        target.setPosition(x, y, 0);
                    }
                })
                .call(() => resolve())
                .start();
        });
    }

    /**
     * 显示 "验证中..." 图标
     */
    private showLoadingIndicator() {
        if (this.loadingIndicator) {
            this.loadingIndicator.active = true;
            // 旋转动画
            tween(this.loadingIndicator)
                .by(1, { angle: -360 })
                .repeatForever()
                .start();
        }
    }

    /**
     * 隐藏 loading 图标
     */
    private hideLoadingIndicator() {
        if (this.loadingIndicator) {
            this.loadingIndicator.active = false;
            this.loadingIndicator.stopAllActions();
        }
    }

    /**
     * 闪烁动画（3秒倒计时 + 中文释义显示）
     */
    private async startBlinkAnimation(word: string, definition: string): Promise<void> {
        console.log(`[SlotQueue] 开始闪烁动画: ${word} - ${definition}`);

        // 1. 高亮匹配的字母
        this.highlightMatchedLetters(word);

        // 2. 显示中文释义气泡（0.5秒淡入）
        await this.showDefinitionBubble(word, definition);

        // 3. 开始3秒倒计时闪烁
        return new Promise(resolve => {
            let countdown = 3;
            const timer = setInterval(() => {
                // 切换高亮状态
                this.toggleBlinkState();
                countdown--;

                if (countdown <= 0) {
                    clearInterval(timer);
                    this.removeMatchedLetters(word); // 消除动画
                    resolve();
                }
            }, 1000);
        });
    }

    /**
     * 显示中文释义气泡
     */
    private async showDefinitionBubble(word: string, definition: string): Promise<void> {
        // 创建气泡 UI（悬浮在牌槽上方）
        // 使用 Tween 淡入动画
        return new Promise(resolve => {
            // 实现细节...
            setTimeout(() => resolve(), 300);
        });
    }

}

async validate(word: string): Promise<ValidateResult> {

    }
}
