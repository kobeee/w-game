## 1. 需求概述

### 1.1 背景

项目当前包含两种完整的游戏玩法：
1. **小试牛刀**（基础玩法）：原有的5×5网格单词拼写玩法（对应 `Game.scene`，由 `GameApp.ts` 控制）
2. **叠叠乐**（新玩法）：新增的字母堆叠消除玩法（对应 `StackGameScene.scene`，由 `StackGameApp.ts` 控制）

### 1.2 需求分析

#### 核心需求
- 在主菜单（MainMenu）的配置面板中添加**游戏模式选择**功能
- 提供两个可选玩法：「小试牛刀」和「叠叠乐」
- 玩家勾选后点击"开始游戏"按钮，根据选择进入对应的游戏场景
- 评估"使用完整词库"开关的必要性并做出决策

#### 功能约束
- 玩法模式必须**互斥选择**（单选，不允许多选）
- 默认选中「小试牛刀」（向后兼容）
- 玩家的选择需要持久化保存到 `localStorage`

## 2. "使用完整词库"开关必要性评估

### 2.1 现状分析

**当前词库系统架构**：
```typescript
// GlossService 词库加载
export enum WordBankLevel {
    CORE = 'core',        // 核心词库：3-7字母，约2158个单词
    EXTENDED = 'extended', // 扩展词库：8字母+，约2483个单词
    FULL = 'full'         // 全量词库：核心+扩展，约4641个单词
}

// 使用方式
await glossService.load(useExtended: boolean);
```

**两种玩法对词库的依赖**：

| 玩法 | 场景 | 词库使用情况 | 是否依赖"完整词库"开关 |
|------|------|------------|---------------------|
| **小试牛刀** | Game.scene | ✅ 使用，初始化时根据 `use_full_dictionary` 决定加载核心还是完整词库 | **是** |
| **叠叠乐** | StackGameScene.scene | ✅ 使用，但**始终加载完整词库**（代码中硬编码 `await glossService.load(false)` 仅核心词库，但实际 IncrementalWordMatcher 会使用所有已加载的单词） | **可选** |

**代码依据**：

```typescript
// GameApp.ts (小试牛刀)
private async initializeGame(): Promise<void> {
    // 检查是否使用完整词库
    const useFull = sys.localStorage.getItem('use_full_dictionary') === 'true';
    await this.glossService.load(useFull);  // ✅ 根据开关决定
    // ...
}

// StackGameApp.ts (叠叠乐)
protected async onLoad(): Promise<void> {
    // ...
    if (!loadStatus.core) {
        await glossService.load(false); // ❌ 硬编码 false，仅加载核心词库
    }
    // 但 IncrementalWordMatcher 实际会使用 glossService.getAllWords()
    // 如果之前在 PreloadManager 中已加载扩展词库，也会被使用
}
```

### 2.2 决策：**保留"使用完整词库"开关**

**理由**：

1. **玩法差异性**：
   - 「小试牛刀」：4-7字母单词，更适合基础玩家（核心词库即可）
   - 「叠叠乐」：支持3-7字母，可扩展到8-10字母的高难度挑战（需要完整词库）

2. **难度梯度**：
   - 初学者可以仅使用核心词库（2158词，覆盖常用单词）
   - 高级玩家可以开启完整词库（4641词，增加挑战性和词汇量）

3. **性能优化**：
   - 核心词库体积更小，加载更快
   - 单词匹配算法在词库量小时性能更好

4. **学习曲线**：
   - 符合「轻学习」理念，玩家可以根据自身水平选择词库范围
   - 扩展词库的8-10字母单词更具挑战性，适合进阶玩家

### 2.3 优化方案

**改进"使用完整词库"的命名和说明**：
- **旧名称**：「使用完整词库」（不够直观）
- **新名称**：「进阶词库」或「挑战模式」（更符合游戏语境）
- **新说明文案**：「包含更多高难度单词（8-10字母）」

**改进后的布局**：
```
┌─────────────────────────────┐
│  ⚙️ 配置面板                │
├─────────────────────────────┤
│  🎮 玩法模式                │
│  ○ 小试牛刀 (基础玩法)      │

│                             │
│  📚 词库设置                │

```

```typescript
private setupButtons(): void {
```

**② 加载设置**

```typescript
private loadSettings(): void {
    // 1. 加载游戏模式设置
    const savedMode = sys.localStorage.getItem(GAME_MODE_STORAGE_KEY);
    this.selectedGameMode = (savedMode as GameMode) || DEFAULT_GAME_MODE;
    
    console.log('[MainMenu] 已加载设置 - 游戏模式:', this.selectedGameMode);
    
    // 同步 UI 状态
    this.syncGameModeUI();
    
    // 2. 加载词库设置
    const useFull = sys.localStorage.getItem('use_full_dictionary');
    const useFullDictionary = useFull === 'true';
    
    if (this.useFullToggle) {
        this.useFullToggle.isChecked = useFullDictionary;
    }
    
    console.log('[MainMenu] 已加载设置 - 使用完整词库:', useFullDictionary);
}
```

**③ 同步游戏模式UI**

```typescript
/**
 * 同步游戏模式 UI 状态
 * 根据 selectedGameMode 更新 Toggle 的选中状态
 */
private syncGameModeUI(): void {
    if (!this.basicModeToggle || !this.stackModeToggle) {
        console.warn('[MainMenu] 游戏模式 Toggle 未设置');
        return;
    }
    
    switch (this.selectedGameMode) {
        case GameMode.BASIC:
            this.basicModeToggle.isChecked = true;
            break;
        case GameMode.STACK:
            this.stackModeToggle.isChecked = true;
            break;
        default:
            console.warn('[MainMenu] 未知的游戏模式:', this.selectedGameMode);
            this.basicModeToggle.isChecked = true; // 默认选中基础玩法
            this.selectedGameMode = GameMode.BASIC;
    }
}
```

**④ 游戏模式切换回调**

```typescript
/**
 * 游戏模式切换回调
 * @param toggle 触发事件的 Toggle 组件
 */
private onGameModeChanged(toggle: Toggle): void {
    if (!toggle.isChecked) {
        // ToggleContainer 保证只有一个 Toggle 被选中
        // 如果当前 Toggle 被取消选中，说明另一个 Toggle 被选中
        return;
    }
    
    // 根据 toggle 的 node.name 判断选中的模式
    const toggleName = toggle.node.name;
    
    if (toggleName === 'BasicModeToggle') {
        this.selectedGameMode = GameMode.BASIC;
    } else if (toggleName === 'StackModeToggle') {
        this.selectedGameMode = GameMode.STACK;
    } else {
        console.warn('[MainMenu] 未知的 Toggle:', toggleName);
        return;
    }
    
    console.log('[MainMenu] 游戏模式切换:', GAME_MODE_CONFIGS[this.selectedGameMode].displayName);
    
    // 实时保存设置
    this.saveSettings();
}
```

**⑤ 保存设置**

```typescript
private saveSettings(): void {
    // 保存游戏模式
    sys.localStorage.setItem(GAME_MODE_STORAGE_KEY, this.selectedGameMode);
    console.log('[MainMenu] 已保存设置 - 游戏模式:', this.selectedGameMode);
    
    // 保存词库设置
    if (this.useFullToggle) {
        const useFull = this.useFullToggle.isChecked;
        sys.localStorage.setItem('use_full_dictionary', useFull ? 'true' : 'false');
        console.log('[MainMenu] 已保存设置 - 使用完整词库:', useFull);
    }
}
```

**⑥ 开始游戏**

```typescript
private onStartGame(): void {
    console.log('[MainMenu] 开始游戏按钮被点击');
    
    // 保存当前设置
    this.saveSettings();
    
    // 获取当前选中模式的场景名称
    const config = GAME_MODE_CONFIGS[this.selectedGameMode];
    const sceneName = config.sceneName;
    
    console.log(`[MainMenu] 跳转到场景: ${sceneName} (${config.displayName})`);
    
    // 跳转到游戏场景
    director.loadScene(sceneName, (error: any) => {
        if (error) {
            console.error(`[MainMenu] 跳转场景失败: ${sceneName}`, error);
        } else {
            console.log(`[MainMenu] 成功跳转到场景: ${sceneName}`);
        }
    });
}
```

**⑦ 清理事件监听**

```typescript
protected onDestroy(): void {
    // 清理事件监听
    if (this.startButton && this.startButton.node) {
        this.startButton.node.off(Button.EventType.CLICK, this.onStartGame, this);
    }
    
    if (this.gameModeToggleContainer && this.gameModeToggleContainer.node) {
        this.gameModeToggleContainer.node.off('toggle', this.onGameModeChanged, this);
    }
    
    if (this.useFullToggle && this.useFullToggle.node) {
        this.useFullToggle.node.off('toggle', this.onToggleChanged, this);
    }
    
    console.log('[MainMenu] 主菜单组件销毁');
}
```
