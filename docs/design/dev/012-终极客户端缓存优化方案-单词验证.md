## 终极客户端缓存优化方案（单词验证）

### 目标
- 将单词验证端到端耗时最小化，显著降低重复外呼比例。
- 缓存既包含“有效单词(valid=true)”也包含“无效单词(valid=false)”及其“中文释义(definition)”。
- 兼容 Cocos 跨平台（Web/原生），不依赖后端即可落地；后续若启用后端/边缘缓存，可自然叠加。

### 适用范围
- 当前架构：本地词库(同步) + Cloudflare Worker(代理 Gemini)。
- 引用模块：`NetworkService.ts`、`WordValidationManager.ts`、`config/word-validate.ts`。

---

### 分层架构（L1/L2）
- L1 会话内 LRU（已实现）
  - 结构：`Map<string, { valid: boolean; definition?: string; source: 'cache' | 'gemini'; expireAt: number }>`
  - 默认 TTL：1 小时（会话期内“热词”0~1ms 命中）
- L2 持久化缓存（本方案新增）
  - Web/通用：`cc.sys.localStorage`（单键大对象，JSON 序列化，批量写入）
  - 原生：`jsb.fileUtils.getWritablePath()` 下 `wc.jsonl`（JSONL 逐行记录 + 启动合并索引 + 旋转）
  - 策略：读写透传 L1；过期/容量控制/LRU 淘汰；批量落盘削减 I/O 抖动

读路径（优先级）：
1) L1 命中（未过期）→ 直接返回
2) L2 命中（未过期）→ 回写 L1 并返回
3) MISS → 发起网络请求（SingleFlight 去重）→ 成功后写回 L1/L2 → 返回

写路径（成功返回即缓存，无论 valid true/false）：
- 统一写入 L1（1h TTL）与 L2（见 TTL 策略），definition 为空时存空串
- 保障 definition ≤ 25 字且为简体中文（不含英文字母）；多余字符截断

---

### 数据模型与键空间
- 统一大写键：`WORD = word.toUpperCase()`
- 存储结构（Entry）：
```json
{
  "v": true,          // valid
  "d": "简体中文释义或空串",
  "t": 1731212345678, // updatedAtMs
  "e": 1731817145678  // expireAtMs
}
```
- 本地持久化键（Web/localStorage）：
  - `wgame_wc_v1`: 词典对象 `{ [WORD]: Entry }`
  - `wgame_wc_meta_v1`: `{ version: 1, size: number, lru: string[] }`（可选：LRU 索引/尺寸统计）
- 原生文件（JSONL）：
  - `wc.jsonl`: 每行一条 `{ k: "WORD", v: Entry }`；启动时顺序合并为内存索引；超过阈值触发“压缩重写”

版本与兼容：
- 通过 `version` 字段控制迁移（形如 `wgame_wc_v2`）；版本不匹配即丢弃旧存储并重建（避免历史结构污染）

---

### TTL 与淘汰策略
- L1（会话）：固定 1h（已存在）
- L2（持久化）：
  - valid=true：7 天
  - valid=false：3 天（负缓存减少抖动，又避免过久锁定）
  - 写入时设置 `e = now + ttlMs`，读取判定 `now <= e` 才算命中
- 容量与 LRU：
  - Web/localStorage 建议软上限 ~5–8MB；超阈值则基于 LRU 移除最老条目直至降到安全阈值
  - 原生 JSONL：文件超过阈值（如 8–12MB）触发“压缩重写”，仅保留最近 N 条与未过期条

---

### 并发与 SingleFlight
- 维持现有 `NetworkService.inflight: Map<string, Promise<...>>`
- 相同 `WORD` 并发只发一次网络请求；其余 await 同一 Promise

---

### 读写流程（伪代码 / TypeScript）
```ts
type Source = 'cache' | 'gemini';
type Entry = { v: boolean; d?: string; t: number; e: number };

const L1_TTL_MS = 60 * 60 * 1000;
const L2_TTL_VALID_MS = 7 * 24 * 60 * 60 * 1000;
const L2_TTL_INVALID_MS = 3 * 24 * 60 * 60 * 1000;
const STORE_KEY = 'wgame_wc_v1';

const l1Cache = new Map<string, { value: { valid: boolean; definition?: string; source: Source }, expireAt: number }>();
const inflight = new Map<string, Promise<{ valid: boolean; definition?: string; source?: Source }>>();

function ensureChinese(def: string | undefined): string {
    if (!def) return '';
    // 简体中文判定 + 截断至 25 字
    const onlyCn = def.replace(/[A-Za-z]/g, '').slice(0, 25).trim();
    return onlyCn;
}

function now(): number { return Date.now(); }

function loadL2(): Record<string, Entry> {
    try {
        const json = cc.sys.localStorage.getItem(STORE_KEY);
        return json ? JSON.parse(json) : {};
    } catch { return {}; }
}

let l2Dict: Record<string, Entry> = loadL2();
let l2DirtyCount = 0;
function flushL2IfNeeded(force = false) {
    if (!force && l2DirtyCount < 16) return; // 批量落盘，降低 I/O
    try {
        cc.sys.localStorage.setItem(STORE_KEY, JSON.stringify(l2Dict));
        l2DirtyCount = 0;
    } catch { /* 容错：忽略写入失败 */ }
}

export async function validateWordWithCache(word: string): Promise<{ valid: boolean; definition?: string; source: Source }> {
    const W = word.toUpperCase();
    const t0 = now();

    // 1) L1
    const c1 = l1Cache.get(W);
    if (c1 && c1.expireAt > t0) {
        return { valid: c1.value.valid, definition: c1.value.definition, source: c1.value.source };
    }

    // 2) L2
    const e = l2Dict[W];
    if (e && e.e > t0) {
        const src: Source = 'cache';
        const def = ensureChinese(e.d || '');
        // 回写 L1
        l1Cache.set(W, { value: { valid: !!e.v, definition: def, source: src }, expireAt: t0 + L1_TTL_MS });
        return { valid: !!e.v, definition: def, source: src };
    }

    // 3) SingleFlight + 网络
    let p = inflight.get(W);
    if (!p) {
        p = actuallyCallGemini(W); // 复用现有 NetworkService 调用
        inflight.set(W, p);
    }
    const res = await p.finally(() => inflight.delete(W));

    const def = ensureChinese(res.definition || '');
    const valid = !!res.valid;
    const src: Source = res.source === 'cache' ? 'cache' : 'gemini';

    // 写回 L1
    l1Cache.set(W, { value: { valid, definition: def, source: src }, expireAt: now() + L1_TTL_MS });

    // 写回 L2（正/负缓存）
    const ttl = valid ? L2_TTL_VALID_MS : L2_TTL_INVALID_MS;
    l2Dict[W] = { v: valid, d: def, t: now(), e: now() + ttl };
    l2DirtyCount++;
    flushL2IfNeeded(false);

    return { valid, definition: def, source: src };
}
```

> 原生（`jsb.fileUtils`）方案：将上面的 `loadL2()/flushL2IfNeeded()` 改为 JSONL 文件读写与压缩重写，接口保持一致即可。

---

### 容量与清理（建议）
- Web/localStorage：当 `JSON.stringify(l2Dict).length` 超过阈值（如 8MB）：
  - 按 `t` 从小到大排序，删除最老的 X%（如 20%）
  - 删除已过期条目
  - 落盘后再次检测，直至回到安全范围
- 原生 JSONL：当 `wc.jsonl` 超过阈值（如 12MB）：
  - 合并索引 + 仅保留最近 N 条 / 未过期条，重写新文件

---

### 指标与日志
- 计数器：`l1_hit / l2_hit / miss / inflight_dedup`、`persist_flush_count`、`evict_count`
- 采样日志：每 200 次请求打印一次命中比例；错误写入只记录摘要

---

### 风险与回滚
- localStorage 写满/异常：读取/写入失败容错为“仅 L1 可用”，不影响游戏流程
- 版本迁移：版本不匹配即丢弃旧缓存，避免结构不一致引发异常

---

### 验收与测试
- 缓存行为
  - 首次 MISS：网络成功后 L1/L2 均可命中
  - 二次同词：L1 命中（<1ms）；重启后：L2 命中（<5ms）并回写 L1
  - 无效词：valid=false 也能在 L1/L2 命中（减少无效外呼）
- 释义规范：始终为简体中文且 ≤ 25 字；无释义时为空串
- 容量控制：压测 5,000~10,000 词条，淘汰过程稳定
- 并发：同一单词并发只发一次网络请求

---

### 结论
上述方案在不依赖后端的前提下，实现“会话 + 持久化”的正/负缓存闭环：热词 0~1ms 命中，冷启动后 5ms 级命中，网络外呼显著减少；与现有代码改动最小，且可平滑进阶到原生 JSONL 落盘与后端/边缘缓存叠加。
