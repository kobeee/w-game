【风格锚点 / Style Key】  
CANDY-MINT-LEMONDRAGON-v1.0

【世界与情绪】  
温暖、软糖感、疗愈、清爽、童趣但不幼稚；画面干净、无噪点、无照片质感。

【画风 DNA】  
- 2D 扁平 + 轻体积；圆角与胶囊造型为主，豆形/圆润比例。  
- 线条：可无描边；若有描边，**等粗 1.5–2.0 px 内描**，不外扩。  
- 光影：单一主光位 **12° 左上**；软投影（**蓝灰色，18–24% 透明度**）；柔和短高光，**禁止强镜面**。  
- 纹理：极简，避免写实肌理与金属拉丝；不使用照片贴图。

【统一色板（Hex）】  
- 主色：糖果蓝 **#7CCEFF**、杏桃橙 **#FFC49A**、薄荷绿 **#8BE0C1**  
- 辅色：薰衣草紫 **#B7A8FF**、柠檬黄 **#FFE680**、奶白 **#F8FAFF**  
规则：**两主一辅**；背景≤3色；整体偏明亮、低对比；**色弱安全**（避免红绿对立）。

【构图与留白】  
主体占画面 **60–70%**；四周**安全边≥8%**；顶部略宽。背景弱化、低纹理密度，不与主体抢焦点。

【像素与抗锯齿】  
以 **2× 或 4×** 分辨率输出；抗锯齿开启；小元素尽量整数像素对齐；边缘干净无毛刺。

【可访问性 / 交互语义（UI/字母卡适用）】  
“可选/可点击”与“禁用/错误”**不仅靠颜色**，还通过描边/明度/形状区分；按钮最小可点击区 44×44px（落地时用）。

【一致性条款】  
同一 IP（角色/图标/道具）在不同请求中保持**比例关系、五官间距、线宽、阴影参数、材质密度**一致；同一套图标**线宽统一**、圆角端一致。**严禁**风格跳变（写实/赛博/像素/黏土/重金属等）。

【禁止项 / Negative】  
写实照片、真实相机/景深虚化、金属拉丝、强镜面高光、复杂反射、HDR 伪彩、胶片颗粒/噪点、强体积雾、过饱和霓虹、血腥/惊悚、文字水印/Logo。

【默认输出规格】  
- **文件**：透明 **PNG**（UI/角色/FX 推荐 PNG-24；大背景可 WebP 透明，如模型/管线支持）。  
- **安全边**：四周 ≥8%。  
- **命名建议**：`{类别}/{名称}_{变体或状态}@2x.png`
