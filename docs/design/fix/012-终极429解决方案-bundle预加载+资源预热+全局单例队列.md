# 终极429解决方案：Bundle预加载 + 资源预热 + 全局单例队列

**创建日期**: 2025-11-23
**目标问题**: 微信小游戏429并发问题 + 资源加载延迟
**方案类型**: 架构级优化（根治方案）

---

## 一、问题根源深度分析

### 1.1 Cocos Creator Bundle机制真相

经过深入调研和真机验证，`assetManager.loadBundle()`的底层行为：

**调用`assetManager.loadBundle(bundleName)`时，引擎实际发起：**
1. **GET `config.json`** - 资源清单文件（包含所有资源的UUID、类型、路径映射）
   - 文件名可能带MD5哈希：`config.a1b2c3d.json`
   - 大小：10-50KB（文本）
   - **独立HTTP请求**

2. **GET `index.js`** - 脚本文件（包含bundle内所有脚本）
   - 文件名可能带MD5哈希：`index.a1b2c3d.js`
   - 大小：5-100KB（文本）
   - **独立HTTP请求**

3. **不加载实际资源** - 只加载清单和脚本，资源在首次使用时才加载

**调用`bundle.load('assetPath')`时：**
- 根据`config.json`的映射，找到资源真实URL
- 发起HTTP请求加载实际资源（图片、JSON、预制体等）
- **每个资源都是独立HTTP请求**

### 1.2 微信小游戏并发限制

官方文档明确规定：
- `wx.request`、`wx.uploadFile`、`wx.downloadFile` **总并发上限为10**
- 超过限制会排队，服务器可能返回429
- 无队列控制时，Cocos默认并发数可达20-30

### 1.3 实际场景计算

**Loading阶段（当前实现）：**
- 5个bundle（bg/title/tiles/slot/words）
- 每个bundle：2个请求（config.json + index.js）
- 小计：5 × 2 = **10个请求**（已达上限）

**Main场景初始化：**
- GameApp：加载bg背景图 + 1个请求
- GlossSheet：加载modal背景 + 1个请求
- LocalDictionary：加载words_core.json + 1个请求
- BloomFilter：加载bloom_filter.json + 1个请求
- 小计：**4个额外请求**

**总计：14个请求 > 10限制 → 触发429**

## 二、现有方案缺陷剖析

### 2.1 方案010（ZIP化）的根本缺陷

**缺陷1：未解决根本问题**
- ZIP化只解决了资源文件（图片、JSON）的下载
- 但Cocos引擎**底层仍然通过XMLHttpRequest加载`config.json`和`index.js`**
- 这些请求绕过ZIP拦截器，直接走微信网络API

**缺陷2：复杂度爆炸**
- +300行代码，引入JSZip、文件系统操作
- 微信`wx.getFileSystemManager().unzip()`兼容性风险
- 不同微信版本（7.0.20 vs 8.0+）API行为不一致

**缺陷3：内存占用高**
- ZIP解压后，内存中存在两份数据：
  - ZIP缓存（用于后续读取）
  - Cocos资源缓存（assetManager）
- 额外占用10-20MB内存，低端机易OOM

**缺陷4：构建流程侵入**
- 需要修改`builder.json`添加hook
- 构建时间增加30-60秒
- 团队协作成本增加

**缺陷5：回退机制不可靠**
- ZIP下载/解压失败时，回退到原始加载
- 但此时可能已触发429，回退请求仍失败

### 2.2 方案011（轻量级）的根本缺陷

**缺陷1：治标不治本**
- `PreloadManager`的并发控制只覆盖`assetManager.loadBundle`调用
- 但**每个bundle内部的`config.json`和`index.js`请求是同时发起的**
- 5个bundle = 10个并发请求，控制失效

**缺陷2：假加载成功**
```typescript
// 当前代码
assetManager.loadBundle('bg', (err, bundle) => {
    // 此时bundle已返回，但资源未加载
    // 进入Main场景后，bundle.load('bg/spriteFrame')仍需等待
});
```
- `loadBundle`回调只表示清单和脚本加载完成
- **不代表资源已反序列化、可用**
- 导致Loading场景快速进入Main，但Main场景空白

**缺陷3：重复加载**
```typescript
// GameApp.ts
assetManager.loadBundle('bg', ...); // 第一次请求

// GlossSheet.ts
assetManager.loadBundle('modal', ...); // 第二次请求

// LocalDictionary.ts
assetManager.loadBundle('words', ...); // 第三次请求
```
- 各模块独立调用，不共享缓存状态
- 即使Loading已加载，Main场景仍会重复请求

**缺陷4：无资源预热**
- 只调用`assetManager.loadBundle`，不预热关键资源
- 进入场景后，首次`bundle.load()`触发真实加载
- 用户体验：点击按钮 → 卡顿 → 资源出现

**缺陷5：缓存机制失效**
- `assetManager.getBundle()`返回null，即使已加载
- 因为Cocos 3.8.7的缓存机制有延迟
- 导致重复调用`loadBundle`

## 三、终极解决方案架构

### 3.1 核心设计原则

**原则1：Bundle完全加载**
- Loading阶段不仅加载清单，还要**完全加载关键资源**
- 使用`bundle.load()`而非`preload()`，确保资源反序列化完成
- 进入Main场景时，资源立即可用

**原则2：资源预热**
- 对每个bundle内的关键资源（背景图、瓦片、UI元素）提前加载
- 确保`SpriteFrame`、`JsonAsset`等已在内存并初始化
- 场景切换后零等待

**原则3：全局单例队列**
- 所有`assetManager.loadBundle`调用必须通过`PreloadManager`
- 维护三个核心状态：
  - `loadedBundles: Map<string, Bundle>` - 已完全加载的bundle
  - `loadingBundles: Map<string, Promise<Bundle>>` - 加载中的bundle
  - `resourceCache: Map<string, Asset>` - 已预热的资源缓存
- 任何模块请求bundle时，先检查缓存，再检查加载中，最后才发起请求

**原则4：场景切换保障**
- 在`director.loadScene`前，调用`PreloadManager.waitForSceneReady(sceneName)`
- 根据场景配置，确保所有必需bundle和资源已预热
- 如有缺失，阻塞场景切换直到加载完成

```typescript
class PreloadManager {
    private loadedBundles = new Map<string, assetmanager.Bundle>();
    private loadingBundles = new Map<string, Promise<assetmanager.Bundle>>();
    
    async ensureBundleLoaded(name: string): Promise<assetmanager.Bundle> {
        // 1. 检查已加载
        if (this.loadedBundles.has(name)) {
            return this.loadedBundles.get(name);
        }
        
        // 2. 检查加载中
        if (this.loadingBundles.has(name)) {
            return this.loadingBundles.get(name);
        }
        
        // 3. 发起加载
        const promise = this.loadBundleInternal(name);
        this.loadingBundles.set(name, promise);
        
        try {
            const bundle = await promise;
            this.loadedBundles.set(name, bundle);
            this.loadingBundles.delete(name);
            return bundle;
        } catch (error) {
            this.loadingBundles.delete(name);
            throw error;
        }
    }
}
```

```typescript
@ccclass('PreloadManager')
export class PreloadManager {
    // 已完全加载的bundle（资源已预热）
    private loadedBundles = new Map<string, assetmanager.Bundle>();
    
    // 正在加载中的bundle（Promise缓存）
    private loadingBundles = new Map<string, Promise<assetmanager.Bundle>>();
    
    // 已预热的资源缓存
    private resourceCache = new Map<string, Asset>();
    
    // Bundle依赖关系（场景 → 所需bundle）
    private sceneBundles = {
        'MainMenu': ['bg', 'title', 'words'],
        'Game': ['bg', 'words', 'tiles'],
        'StackGameScene': ['bg', 'words', 'tiles', 'slot'],
        'Result': ['bg', 'modal']
    };
}
```

**步骤1.2：添加ensureBundleLoaded方法**

```typescript
/**
 * 确保Bundle已加载（全局单例，避免重复请求）
 * @param bundleName Bundle名称
 * @returns 已加载的Bundle实例
 */
public async ensureBundleLoaded(bundleName: string): Promise<assetmanager.Bundle> {
    // 1. 检查已加载缓存
    const cached = this.loadedBundles.get(bundleName);
    if (cached) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 已从已加载缓存返回`);
        return cached;
    }
    
    // 2. 检查加载中缓存
    const loading = this.loadingBundles.get(bundleName);
    if (loading) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 正在加载中，返回Promise`);
        return loading;
    }
    
    // 3. 发起新加载
    console.log(`[PreloadManager] Bundle '${bundleName}' 未加载，开始加载...`);
    const promise = this.loadBundleInternal(bundleName);
    this.loadingBundles.set(bundleName, promise);
    
    try {
        const bundle = await promise;
        this.loadedBundles.set(bundleName, bundle);
        this.loadingBundles.delete(bundleName);
        console.log(`[PreloadManager] Bundle '${bundleName}' 加载完成并缓存`);
        return bundle;
    } catch (error) {
        this.loadingBundles.delete(bundleName);
        console.error(`[PreloadManager] Bundle '${bundleName}' 加载失败:`, error);
        throw error;
    }
}

/**
 * 内部加载方法（带429重试）
 */
private async loadBundleInternal(bundleName: string): Promise<assetmanager.Bundle> {
    return new Promise((resolve, reject) => {
        let attempts = 0;
        const maxAttempts = 3;
        
        const tryLoad = () => {
            attempts++;
            assetManager.loadBundle(bundleName, (err, bundle) => {
                if (err) {
                    // 检测429错误
                    if (err.message && err.message.includes('429') && attempts < maxAttempts) {
                        console.warn(`[PreloadManager] Bundle '${bundleName}' 遇到429，${attempts}秒后重试...`);
                        setTimeout(tryLoad, attempts * 1000);
                        return;
                    }
                    reject(err);
                    return;
                }
                resolve(bundle);
            });
        };
        
        tryLoad();
    });
}
```

**步骤1.3：添加资源预热方法**

```typescript
/**
 * 预热Bundle内的关键资源（完全加载并缓存）
 */
public async preloadCriticalAssets(bundleName: string): Promise<void> {
    const bundle = await this.ensureBundleLoaded(bundleName);
    
    const criticalAssets = {
        'bg': ['game_scene_bg/spriteFrame', 'main_scene_bg/spriteFrame'],
        'title': ['title/spriteFrame'],
        'tiles': ['tile_selectable/spriteFrame', 'tile_correct/spriteFrame'],
        'words': ['words_core', 'zh_gloss'],
        'modal': ['pop_card/spriteFrame']
    };
    
    const assets = criticalAssets[bundleName] || [];
    if (assets.length === 0) return;
    
    console.log(`[PreloadManager] 开始预热 ${bundleName} 的 ${assets.length} 个关键资源...`);
    
    await Promise.all(
        assets.map(assetPath => this.preloadAsset(bundle, bundleName, assetPath))
    );
    
    console.log(`[PreloadManager] ${bundleName} 的关键资源预热完成`);
}

/**
 * 预热单个资源
 */
private async preloadAsset(bundle: assetmanager.Bundle, bundleName: string, assetPath: string): Promise<void> {
    const cacheKey = `${bundleName}:${assetPath}`;
    
    // 检查资源缓存
    if (this.resourceCache.has(cacheKey)) {
        return;
    }
    
    return new Promise((resolve, reject) => {
        const assetType = assetPath.includes('/spriteFrame') ? SpriteFrame : JsonAsset;
        
        bundle.load(assetPath, assetType, (err, asset) => {
            if (err) {
                console.warn(`[PreloadManager] 预热资源失败 ${cacheKey}:`, err);
                reject(err);
                return;
            }
            
            this.resourceCache.set(cacheKey, asset);
            console.log(`[PreloadManager] 资源预热完成: ${cacheKey}`);
            resolve();
        });
    });
}
```

**步骤1.4：添加场景切换保障**

```typescript
/**
 * 等待场景准备就绪（所有必需bundle和资源已加载）
 */
public async waitForSceneReady(sceneName: string): Promise<void> {
    const requiredBundles = this.sceneBundles[sceneName] || [];
    
    if (requiredBundles.length === 0) {
        console.warn(`[PreloadManager] 场景 '${sceneName}' 未配置bundle依赖`);
        return;
    }
    
    console.log(`[PreloadManager] 等待场景 '${sceneName}' 准备就绪...`);
    
    // 1. 确保所有必需bundle已加载
    await Promise.all(
        requiredBundles.map(bundleName => this.ensureBundleLoaded(bundleName))
    );
    
    console.log(`[PreloadManager] 场景 '${sceneName}' 的所有bundle已加载`);
    
    // 2. 预热关键资源（可选，根据场景类型）
    if (sceneName === 'Game' || sceneName === 'StackGameScene') {
        await this.preloadCriticalAssets('tiles');
    }
    
    console.log(`[PreloadManager] 场景 '${sceneName}' 已准备就绪`);
}
```

**文件**：`src/cocos/assets/scripts/app/LoadingScene.ts`

**修改`onLoad`方法：**

```typescript
protected async onLoad(): Promise<void> {
    try {
        const preloadManager = PreloadManager.getInstance();
        preloadManager.setProgressCallback((progress, message) => {
            if (this.loadingUI) {
                this.loadingUI.updateProgress(progress, message);
            }
        });

        // 1. 配置场景bundle依赖（明确告知需要哪些bundle）
        const startupBundles = ['bg', 'title', 'words'];
        
        // 2. 串行加载bundle（避免429）
        for (let i = 0; i < startupBundles.length; i++) {
            const bundleName = startupBundles[i];
            const progress = (i + 1) / startupBundles.length * 0.7;
            
            this.loadingUI.updateProgress(progress, `正在加载核心资源包 ${bundleName}...`);
            
            // 确保bundle加载完成
            await preloadManager.ensureBundleLoaded(bundleName);
            
            // 立即预热关键资源
            await preloadManager.preloadCriticalAssets(bundleName);
        }
        
        this.loadingUI.updateProgress(0.8, '正在初始化词库服务...');
        
        // 3. 加载词库数据（使用已预热的bundle）
        await this.loadGlossData();
        
        this.loadingUI.updateProgress(0.9, '正在准备游戏场景...');
        
        // 4. 后台静默加载剩余bundle（不阻塞）
        const backgroundBundles = ['tiles', 'slot', 'modal'];
        backgroundBundles.forEach(bundleName => {
            preloadManager.ensureBundleLoaded(bundleName)
                .then(() => preloadManager.preloadCriticalAssets(bundleName))
                .catch(err => console.warn(`[LoadingScene] ${bundleName} 后台加载失败:`, err));
        });
        
        this.loadingUI.updateProgress(1.0, '加载完成，进入游戏...');
        
        // 5. 等待一帧，确保进度条显示100%
        await new Promise(resolve => setTimeout(resolve, 100));
        
        // 6. 安全切换场景（所有资源已预热）
        director.loadScene('MainMenu');
        
    } catch (error) {
        console.error('[LoadingScene] 加载失败:', error);
        // 降级：即使失败也进入主菜单
        director.loadScene('MainMenu');
    }
}

private async loadGlossData(): Promise<void> {
    const glossService = GlossService.getInstance();
    await glossService.load(false); // 只加载核心词库
    
    const wordCount = glossService.getAllWords().length;
    console.log(`[LoadingScene] 词库加载完成，共 ${wordCount} 个单词`);
}
```

```typescript
/**
 * 动态加载远程Asset Bundle资源（使用PreloadManager）
 */
private async loadRemoteAssets(): Promise<void> {
    try {
        const preloadManager = PreloadManager.getInstance();
        
        // 确保bg bundle已加载（Loading阶段应该已完成）
        const bgBundle = await preloadManager.ensureBundleLoaded('bg');
        
        // 从缓存获取资源（已预热）
        const cacheKey = 'bg:game_scene_bg/spriteFrame';
        const cachedAsset = preloadManager.getCachedResource(cacheKey);
        
        if (cachedAsset && cachedAsset instanceof SpriteFrame) {
            // 资源已预热，直接使用
            if (this.backgroundSprite) {
                this.backgroundSprite.spriteFrame = cachedAsset;
            }
        } else {
            // 降级：从bundle加载（理论上不会发生）
            const spriteFrame = await this.loadSpriteFrameFromBundle(bgBundle, 'game_scene_bg/spriteFrame');
            if (this.backgroundSprite && spriteFrame) {
                this.backgroundSprite.spriteFrame = spriteFrame;
            }
        }
        
        // 确保words bundle已加载
        await preloadManager.ensureBundleLoaded('words');
        
    } catch (error) {
        console.error('[GameApp] 远程资源加载失败:', error);
    }
}

/**
 * 从Bundle加载SpriteFrame（辅助方法）
 */
private loadSpriteFrameFromBundle(bundle: assetmanager.Bundle, path: string): Promise<SpriteFrame> {
    return new Promise((resolve, reject) => {
        bundle.load(path, SpriteFrame, (err, spriteFrame) => {
            if (err) reject(err);
            else resolve(spriteFrame);
        });
    });
}
```

```typescript
private async loadCoreDict(): Promise<void> {

        // 使用PreloadManager确保words Bundle已加载
        const preloadManager = PreloadManager.getInstance();
        const bundle = await preloadManager.ensureBundleLoaded('words');
        
        const mergeJson = (asset?: JsonAsset | null) => {
            if (asset && asset.json) {
                for (const [word, definition] of Object.entries(asset.json)) {
                    if (typeof definition === 'string') {
                        this.coreDict.set(String(word).toUpperCase(), definition);
                    }
                }
            }
        };
        
        // 从bundle加载（已预热，立即返回）
        await new Promise<void>((resolve) => {
            bundle.load('zh_gloss', JsonAsset, (loadErr, asset) => {
                if (loadErr) {
                    console.warn('[LocalDictionary] 核心词库释义加载失败');
                } else {
                    mergeJson(asset);
                }
                
                // 加载自定义词库
                bundle.load('zh_gloss_custom', JsonAsset, (cusErr, cusAsset) => {
                    if (!cusErr) {
                        mergeJson(cusAsset);
                    }
                    resolve();
                });
            });
        });
    } catch (error) {
```

## 七、风险评估

### 7.1 风险等级：低

### 7.2 潜在风险与应对

| 风险点 | 概率 | 影响 | 应对措施 |
|--------|------|------|----------|
| Cocos缓存API延迟 | 中 | 中 | 使用自维护Map作为降级 |
| 资源预热失败 | 低 | 低 | 降级到运行时加载 |
| 场景配置遗漏 | 低 | 高 | 添加单元测试验证配置 |
| 低端机内存不足 | 中 | 中 | 监控内存，超阈值跳过预热 |

### 7.3 降级策略
