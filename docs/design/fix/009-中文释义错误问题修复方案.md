# 中文释义错误问题修复方案

## 问题描述

**问题编号**：009
**严重等级**：🔴 高
**影响范围**：后端单词验证服务

### 症状

用户在游戏中看到错误的中文释义：

1. **BAS** 被翻译为 "基础"（实际上 BAS 不是有效的英文单词）
2. **BAI** 被翻译为 "白色"（实际上 BAI 不是有效的英文单词）
3. 其他短单词也可能出现类似问题

### 预期行为

1. 无效单词应该返回 `{"valid": false, "definition": ""}`
2. 只有通过字典验证的真实英文单词才应该返回中文释义

---

## 根因分析

### 核心问题

#### 问题点 1：dictionaryapi.dev 验证缺失

**位置**：`src/backend/word_validator.py` L300

**当前代码**：
```python
# 单词已通过 dictionaryapi.dev 验证，这里仅返回中文释义
return {"valid": True, "definition": parsed.get("definition", "")}
```

**问题**：
- 注释说"已通过 dictionaryapi.dev 验证"
- 但实际代码中**没有**调用 dictionaryapi.dev
- 直接跳到 Gemini 调用，导致伪单词也被接受

#### 问题点 2：Gemini 被用于验证，产生幻觉

**位置**：`src/backend/word_validator.py` L235-239

**当前提示词**：
```python
prompt = (
    f"给出单词\"{word}\"的简体中文释义（≤10字，简洁直白）。\n"
    f"仅返回JSON，格式：{{\"definition\": \"中文释义\"}}\n"
    f"禁止任何非JSON内容（含Markdown、说明、代码块）。"
)
```

**问题**：
- Gemini 是语言模型，不是字典
- 对于无效输入（BAS、BAI），Gemini 会：
  - 猜测或联想（BAS → BASIS → "基础"）
  - 拼音匹配（BAI → "白" → "白色"）
  - 产生"幻觉"（提供似是而非的答案）

#### 问题点 3：没有失败处理机制

**位置**：`src/backend/word_validator.py` L303

**当前代码**：
```python
return {
    "valid": True,
    "definition": parsed.get("definition", ""),
}
```

**问题**：
- 无论 Gemini 返回什么，都被无条件接受
- 没有验证释义是否合理
- 没有拒绝"幻觉"回答的机制

#### 问题点 4：错误缓存无法自动修正

**位置**：Redis 缓存

**问题**：
- 一旦错误的释义被缓存（如 `word:BAS = "基础"`）
- 下次请求会直接返回缓存，不重新验证
- 错误会持续存在

## 修复方案

### 修复点 1：实现 dictionaryapi.dev 验证

**文件**：`src/backend/word_validator.py`

**新增函数**：
```python
import httpx
from typing import Optional

async def verify_with_dictionary_api(word: str) -> Optional[dict]:
    """
    使用 dictionaryapi.dev 验证单词是否存在

    Args:
        word: 待验证的单词

    Returns:
        如果单词有效，返回字典数据；否则返回 None
    """
    try:
        url = f"https://api.dictionaryapi.dev/api/v2/entries/en/{word.lower()}"

        logger.info(f"[DICT] 调用 dictionaryapi.dev: word={word}, url={url}")

        async with httpx.AsyncClient(timeout=5.0) as client:
            response = await client.get(url)

            if response.status_code == 200:
                data = response.json()
                logger.info(f"[DICT] 验证通过: word={word}")
                return data
            elif response.status_code == 404:
                logger.info(f"[DICT] 验证失败: word={word} (404 Not Found)")
                return None
            else:
                logger.warning(f"[DICT] 返回异常状态: {response.status_code}")
                return None

    except httpx.TimeoutException:
        logger.warning(f"[DICT] 超时: word={word}")
        return None
    except Exception as e:
        logger.error(f"[DICT] 调用失败: word={word}, error={e}")
        return None
```

```python
        f"2. 仅翻译该单词的主要含义，不要联想、不要猜测\n"
        f"3. 如果你不确定或不知道，返回 {{\"definition\": \"\"}}\n"
        f"\n"
        f"输出格式: 仅返回JSON，格式：{{\"definition\": \"中文释义\"}}\n"
        f"禁止任何非JSON内容（含Markdown、说明、代码块）。"
    )

    logger.info(f"[GEMINI] 提示词: {prompt[:100]}...")

    try:
        result = await gemini_client.generate_content(prompt)
        text = result["candidates"][0]["content"]["parts"][0]["text"]

        logger.info(f"[GEMINI] 原始返回: {text}")

        parsed = _try_parse(text)

        logger.info(f"[GEMINI] 解析后: {parsed}")

        definition = parsed.get("definition", "")

        # ✅ 修复点 4：验证释义是否为空
        if not definition or len(definition.strip()) == 0:
            logger.warning(f"[GEMINI] 返回空释义: word={word}")
            return {"valid": False, "definition": ""}

        logger.info(f"[VERIFY] 最终返回: {{'valid': True, 'definition': '{definition}'}}")
        return {"valid": True, "definition": definition}

    except Exception as e:
        logger.error(f"[GEMINI] 调用失败: word={word}, error={e}")
        return {"valid": False, "definition": ""}
```

**改进点**：
1. 先验证单词，后调用 Gemini
2. 改进提示词，明确说明"已验证的单词"
3. 验证 Gemini 返回的释义是否为空
4. 添加详细日志

### 修复点 3：清理错误缓存

**文件**：`tools/cleanup_invalid_cache.py`

```python
#!/usr/bin/env python3
"""
清理 Redis 中的无效单词缓存
"""

import redis
import requests
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# 连接 Redis
r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)

def verify_word_with_dict_api(word: str) -> bool:
    """使用 dictionaryapi.dev 验证单词"""
    try:
        url = f"https://api.dictionaryapi.dev/api/v2/entries/en/{word.lower()}"
        response = requests.get(url, timeout=5)
        return response.status_code == 200
    except Exception as e:
        logger.error(f"验证失败: {word}, error={e}")
        return False

def cleanup_invalid_words():
    """清理无效的单词缓存"""
    # 扫描所有 word:* 的键
    cursor = 0
    deleted_count = 0
    checked_count = 0

    while True:
        cursor, keys = r.scan(cursor, match='word:*', count=100)

        for key in keys:
            word = key.replace('word:', '')
            checked_count += 1

            # 验证单词
            if not verify_word_with_dict_api(word):
                logger.info(f"❌ 删除无效单词: {word}")
                r.delete(key)
                deleted_count += 1
            else:
                logger.info(f"✅ 保留有效单词: {word}")

        if cursor == 0:
            break

    logger.info(f"\n清理完成:")
    logger.info(f"  检查: {checked_count} 个单词")
    logger.info(f"  删除: {deleted_count} 个无效单词")

if __name__ == '__main__':
    cleanup_invalid_words()
```

**使用方法**：
```bash
# 安装依赖
pip install redis requests

# 运行清理脚本
python tools/cleanup_invalid_cache.py
```
