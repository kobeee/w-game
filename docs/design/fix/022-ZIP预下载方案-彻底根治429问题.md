# 022-ZIP预下载方案：彻底根治微信小游戏429问题

## 一、问题背景

### 1.1 当前现状

微信小游戏环境下，资源加载频繁触发 HTTP 429 错误（Too Many Requests），导致：
- Loading 阶段用户等待时间过长
- 进入游戏场景后资源加载失败
- 背景图黑屏、音效不播放等用户体验问题

### 1.2 根本原因分析

#### 远程资源包实际构成

```
remote/ (6.1MB, 111个文件)
├── bundle/     (5.7MB, 63个文件)  <- 主要资源
├── resources/  (296KB, 44个文件)  <- 场景/预制体配置
├── internal/   (32KB, 2个文件)   <- 内部配置
└── main/       (24KB, 2个文件)   <- 主包配置
```

**关键数据**：
- 源文件：29个 → 构建产物：**111个文件**
- 每个资源除了本身，还有对应的配置 JSON
- Cocos 构建会生成额外的索引和配置文件

#### 429 发生机制

```
111个文件 vs 微信10并发限制 = 必然429

即使 WXNetworkGate 限制并发为3：
- 最少需要 111/3 = 37 轮请求
- 加上网络波动、服务器限流，429 几乎不可避免
```

#### 已实施但未根治的措施

| 措施 | 效果 |
|------|------|
| WXNetworkGate 并发控制 (3个) | 部分有效，但 Cocos 内部可能绕过 |
| 熔断机制 (2s 冷却) | 触发后用户体验差 |
| Bundle 合并 (6→1) | 减少了请求数，但仍有 111 个文件 |
| 分级加载 | 有效，但启动阶段仍需大量资源 |

### 1.3 解决思路

**核心目标**：将 111 次 HTTP 请求减少到 2-4 次

**方案**：ZIP 预下载 + 本地解压 + Cocos 本地路径加载

```
传统流程：
Cocos assetManager.loadBundle(远程URL) 
  → 111次 wx.downloadFile 
  → 429错误

优化后流程：
wx.downloadFile(bundle.zip) [1次请求]
  → wx.getFileSystemManager().unzip() [本地解压]
  → assetManager.loadBundle(本地路径) [无网络请求]
  → 资源立即可用
```

### 2.1 整体架构

```
├─────────────────────────────────────────────────────────────┤

│     ├── wx.downloadFile(resources.zip)  [1个请求, 296KB]    │

│                                                             │

│     └── assetManager.loadBundle(本地路径)                    │
│         → 无网络请求，直接从本地文件系统读取                   │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 ZIP 打包策略

#### 方案 A：单 ZIP（推荐）

```
remote.zip (6.1MB)
├── bundle/
├── resources/
├── internal/
└── main/
```

**优点**：
- 最少请求数（1次）
- 实现最简单
- 解压一次完成

**缺点**：
- 单文件较大，下载失败需全部重来

#### 方案 B：分目录 ZIP

```
bundle.zip      (5.7MB) - 主要资源
resources.zip   (296KB) - 场景配置
internal.zip    (32KB)  - 内部配置（可内置）
main.zip        (24KB)  - 主配置（可内置）
```

**优点**：
- 下载失败可部分重试
- 可按需加载

**缺点**：
- 请求数略多（2-4次）
- 解压逻辑稍复杂

#### 推荐选择

**方案 A（单 ZIP）**，原因：
1. 6.1MB 不算大，下载失败概率低
2. 实现最简单
3. 即使失败，重新下载一次也可接受

### 2.3 本地缓存目录结构



### 3.2 ZipPreloader.ts 核心实现

```typescript
/**
 * ZIP 预加载管理器
 * 负责下载、解压、版本管理
 */
import { sys } from 'cc';

interface VersionInfo {
    version: string;
    buildTime: string;
    zipHash: string;
}

export class ZipPreloader {
    private static _instance: ZipPreloader = null;
    
    // 配置
    private readonly REMOTE_BASE_URL = 'https://ai.elvis1949.cloudns.pro/w-game-remote';
    private readonly ZIP_FILENAME = 'remote.zip';
    private readonly LOCAL_CACHE_DIR = 'w-game-cache';
    private readonly VERSION_FILE = 'version.json';
    
    // 状态
    private isWeChatEnv: boolean = false;
    private localCachePath: string = '';
    private progressCallback: (progress: number, message: string) => void = null;
    
    public static getInstance(): ZipPreloader {
        if (!ZipPreloader._instance) {
            ZipPreloader._instance = new ZipPreloader();
        }
        return ZipPreloader._instance;
    }
    
    constructor() {
        this.isWeChatEnv = typeof wx !== 'undefined';
        if (this.isWeChatEnv) {
            this.localCachePath = `${wx.env.USER_DATA_PATH}/${this.LOCAL_CACHE_DIR}`;
        }
    }
    
    /**
     * 设置进度回调
     */
    public setProgressCallback(callback: (progress: number, message: string) => void): void {
        this.progressCallback = callback;
    }
    
    /**
     * 主入口：确保资源已准备就绪
     * @returns 本地缓存路径（供 assetManager.loadBundle 使用）
     */
    public async ensureResourcesReady(): Promise<string> {
        if (!this.isWeChatEnv) {
            console.log('[ZipPreloader] 非微信环境，跳过 ZIP 预加载');
            return '';
        }
        
        this.reportProgress(0, '正在检查资源缓存...');
        
        // 1. 检查本地缓存
        const needsDownload = await this.checkNeedsDownload();
        
        if (!needsDownload) {
            console.log('[ZipPreloader] 本地缓存有效，跳过下载');
            this.reportProgress(1, '资源缓存已就绪');
            return this.localCachePath;
        }
        
        // 2. 下载 ZIP
        this.reportProgress(0.1, '正在下载资源包...');
        const zipPath = await this.downloadZip();
        
        // 3. 解压 ZIP
        this.reportProgress(0.7, '正在解压资源...');
        await this.unzipToCache(zipPath);
        
        // 4. 清理临时文件
        await this.cleanupTempFile(zipPath);
        
        // 5. 保存版本信息
        await this.saveVersionInfo();
        
        this.reportProgress(1, '资源准备完成');
        console.log('[ZipPreloader] ZIP 预加载完成');
        
        return this.localCachePath;
    }
    
    /**
     * 检查是否需要下载
     */
    private async checkNeedsDownload(): Promise<boolean> {
        try {
            const fs = wx.getFileSystemManager();
            const versionPath = `${this.localCachePath}/${this.VERSION_FILE}`;
            
            // 检查版本文件是否存在
            try {
                fs.accessSync(versionPath);
            } catch (e) {
                console.log('[ZipPreloader] 版本文件不存在，需要下载');
                return true;
            }
            
            // 读取本地版本
            const localVersionStr = fs.readFileSync(versionPath, 'utf8') as string;
            const localVersion: VersionInfo = JSON.parse(localVersionStr);
            
            // 获取远程版本（可选：通过 API 或静态文件）
            // 这里简化处理：只检查本地文件完整性
            const bundleConfigPath = `${this.localCachePath}/bundle/config.json`;
            try {
                fs.accessSync(bundleConfigPath);
                console.log('[ZipPreloader] 本地缓存完整，版本:', localVersion.version);
                return false;
            } catch (e) {
                console.log('[ZipPreloader] 本地缓存不完整，需要重新下载');
                return true;
            }
            
        } catch (error) {
            console.warn('[ZipPreloader] 检查缓存失败，将重新下载:', error);
            return true;
        }
    }
    
    /**
     * 下载 ZIP 文件
     */
    private downloadZip(): Promise<string> {
        return new Promise((resolve, reject) => {
            const zipUrl = `${this.REMOTE_BASE_URL}/${this.ZIP_FILENAME}`;
            console.log('[ZipPreloader] 开始下载:', zipUrl);
            
            const downloadTask = wx.downloadFile({
                url: zipUrl,
                success: (res) => {
                    if (res.statusCode === 200) {
                        console.log('[ZipPreloader] ZIP 下载完成:', res.tempFilePath);
                        resolve(res.tempFilePath);
                    } else {
                        reject(new Error(`下载失败，状态码: ${res.statusCode}`));
                    }
                },
                fail: (err) => {
                    reject(new Error(`下载失败: ${err.errMsg}`));
                }
            });
            
            // 监听下载进度
            downloadTask.onProgressUpdate((res) => {
                // 下载进度映射到 0.1 - 0.7
                const progress = 0.1 + (res.progress / 100) * 0.6;
                this.reportProgress(progress, `正在下载资源包 ${res.progress}%`);
            });
        });
    }
    
    /**
     * 解压 ZIP 到缓存目录
     */
    private unzipToCache(zipPath: string): Promise<void> {
        return new Promise((resolve, reject) => {
            const fs = wx.getFileSystemManager();
            
            // 先清理旧缓存
            try {
                this.removeDirectory(this.localCachePath);
            } catch (e) {
                // 目录不存在，忽略
            }
            
            // 创建缓存目录
            try {
                fs.mkdirSync(this.localCachePath, true);
            } catch (e) {
                // 目录已存在，忽略
            }
            
            console.log('[ZipPreloader] 开始解压到:', this.localCachePath);
            
            fs.unzip({
                zipFilePath: zipPath,
                targetPath: this.localCachePath,
                success: () => {
                    console.log('[ZipPreloader] 解压完成');
                    resolve();
                },
                fail: (err) => {
                    reject(new Error(`解压失败: ${err.errMsg}`));
                }
            });
        });
    }
    
    /**
     * 递归删除目录
     */
    private removeDirectory(dirPath: string): void {
        const fs = wx.getFileSystemManager();
        
        try {
            const files = fs.readdirSync(dirPath);
            files.forEach(file => {
                const filePath = `${dirPath}/${file}`;
                const stat = fs.statSync(filePath);
                if (stat.isDirectory()) {
                    this.removeDirectory(filePath);
                } else {
                    fs.unlinkSync(filePath);
                }
            });
            fs.rmdirSync(dirPath);
        } catch (e) {
            // 忽略错误
        }
    }
    
    /**
     * 清理临时文件
     */
    private cleanupTempFile(tempPath: string): Promise<void> {
        return new Promise((resolve) => {
            try {
                const fs = wx.getFileSystemManager();
                fs.unlinkSync(tempPath);
                console.log('[ZipPreloader] 临时文件已清理');
            } catch (e) {
                // 忽略错误
            }
            resolve();
        });
    }
    
    /**
     * 保存版本信息
     */
    private saveVersionInfo(): Promise<void> {
        return new Promise((resolve) => {
            try {
                const fs = wx.getFileSystemManager();
                const versionInfo: VersionInfo = {
                    version: '1.0.0',
                    buildTime: new Date().toISOString(),
                    zipHash: ''  // 可选：ZIP 文件 MD5
                };
                
                const versionPath = `${this.localCachePath}/${this.VERSION_FILE}`;
                fs.writeFileSync(versionPath, JSON.stringify(versionInfo), 'utf8');
                console.log('[ZipPreloader] 版本信息已保存');
            } catch (e) {
                console.warn('[ZipPreloader] 保存版本信息失败:', e);
            }
            resolve();
        });
    }
    
    /**
     * 报告进度
     */
    private reportProgress(progress: number, message: string): void {
        if (this.progressCallback) {
            this.progressCallback(progress, message);
        }
    }
    
    /**
     * 获取本地缓存路径（供其他模块使用）
     */
    public getLocalCachePath(): string {
        return this.localCachePath;
    }
    
    /**
     * 检查是否有本地缓存
     */
    public hasLocalCache(): boolean {
        if (!this.isWeChatEnv) return false;
        
        try {
            const fs = wx.getFileSystemManager();
            const bundleConfigPath = `${this.localCachePath}/bundle/config.json`;
            fs.accessSync(bundleConfigPath);
            return true;
        } catch (e) {
            return false;
        }
    }
    
    /**
     * 清除本地缓存（用于调试或强制更新）
     */
    public clearCache(): void {
        if (!this.isWeChatEnv) return;
        
        try {
            this.removeDirectory(this.localCachePath);
            console.log('[ZipPreloader] 缓存已清除');
        } catch (e) {
            console.warn('[ZipPreloader] 清除缓存失败:', e);
        }
    }
}
```

```typescript
// 在 PreloadManager 类中添加/修改以下内容

import { ZipPreloader } from '../core/ZipPreloader';

/**
 * 🚀 优化版：启动资源加载（ZIP 预下载版）
 */
public async preloadStartupBundles(): Promise<void> {
    console.log('[PreloadManager] 🚀 开始启动阶段资源加载...');
    
    // 微信环境：优先使用 ZIP 预下载
    if (typeof wx !== 'undefined') {
        await this.preloadWithZip();
    } else {
        // 浏览器环境：使用原有逻辑
        await this.preloadWithRemote();
    }
}

/**
 * 微信环境：ZIP 预下载 + 本地 Bundle 加载
 */
private async preloadWithZip(): Promise<void> {
    const zipPreloader = ZipPreloader.getInstance();
    
    // 传递进度回调
    zipPreloader.setProgressCallback((progress, message) => {
        // ZIP 下载占 0 - 0.5 进度
        this.reportProgress(progress * 0.5, message);
    });
    
    // 1. 确保 ZIP 资源已下载并解压
    const localCachePath = await zipPreloader.ensureResourcesReady();
    
    if (!localCachePath) {
        console.warn('[PreloadManager] ZIP 预加载失败，回退到远程加载');
        await this.preloadWithRemote();
        return;
    }
    
    // 2. 从本地路径加载 Bundle
    this.reportProgress(0.5, '正在加载本地资源...');
    
    try {
        // 加载 bundle（从本地路径）
        const bundlePath = `${localCachePath}/bundle`;
        await this.loadBundleFromPath(bundlePath, 'bundle');
        this.reportProgress(0.7, 'Bundle 加载完成');
        
        // 3. 预热关键资源
        await this.preloadCriticalAssetsWithProgress(0.7, 0.9);
        
        // 4. 加载词库
        await this.loadGlossDataWithProgress(0.9, 0.95, false);
        
        this.reportProgress(0.95, '资源加载完成');
        
    } catch (error) {
        console.error('[PreloadManager] 本地 Bundle 加载失败:', error);
        // 回退到远程加载
        await this.preloadWithRemote();
    }
}

/**
 * 从本地路径加载 Bundle
 */
private loadBundleFromPath(path: string, bundleName: string): Promise<void> {
    return new Promise((resolve, reject) => {
        console.log(`[PreloadManager] 从本地路径加载 Bundle: ${path}`);
        
        assetManager.loadBundle(path, (err, bundle) => {
            if (err) {
                console.error(`[PreloadManager] Bundle 加载失败: ${bundleName}`, err);
                reject(err);
                return;
            }
            
            console.log(`[PreloadManager] ✅ Bundle 加载成功: ${bundleName}`);
            this.loadedBundles.set(bundleName, bundle);
            resolve();
        });
    });
}

/**
 * 浏览器环境/回退：使用原有远程加载逻辑
 */
private async preloadWithRemote(): Promise<void> {
    // ... 原有的 preloadStartupBundles 逻辑
    this.reportProgress(0, '正在初始化核心资源加载...');
    
    // 加载单个 Bundle
    await this.loadSingleBundle(this.BUNDLE_NAME, 0, 0.3);
    
    // 预热关键资源
    await this.preloadCriticalAssetsWithProgress(0.3, 0.8);
    
    // 核心词库加载
    await this.loadGlossDataWithProgress(0.8, 0.95, false);
    
    this.reportProgress(0.95, '核心资源加载完成');
}
```

### 3.4 构建后处理脚本 build-zip.js

```javascript
/**
 * build-zip.js
 * 构建后处理脚本：将 remote 目录打包成 ZIP
 * 
 * 使用方法：
 * 1. npm install archiver
 * 2. node tools/build-zip.js
 */

const fs = require('fs');
const path = require('path');
const archiver = require('archiver');

// 配置
const BUILD_PATH = path.join(__dirname, '../src/cocos/build/wechatgame');
const REMOTE_PATH = path.join(BUILD_PATH, 'remote');
const OUTPUT_PATH = path.join(REMOTE_PATH, '../remote.zip');

async function buildZip() {
    // 检查 remote 目录是否存在
    if (!fs.existsSync(REMOTE_PATH)) {
        console.error('❌ remote 目录不存在:', REMOTE_PATH);
        console.log('请先在 Cocos Creator 中构建微信小游戏');
        process.exit(1);
    }
    
    console.log('📦 开始打包 remote 目录...');
    console.log('源目录:', REMOTE_PATH);
    console.log('输出文件:', OUTPUT_PATH);
    
    // 创建输出流
    const output = fs.createWriteStream(OUTPUT_PATH);
    const archive = archiver('zip', {
        zlib: { level: 9 } // 最高压缩级别
    });
    
    // 监听事件
    output.on('close', () => {
        const sizeInMB = (archive.pointer() / 1024 / 1024).toFixed(2);
        console.log(`✅ ZIP 打包完成: ${sizeInMB} MB`);
        console.log(`文件位置: ${OUTPUT_PATH}`);
        
        // 统计原始文件数量
        let fileCount = 0;
        const countFiles = (dir) => {
            const files = fs.readdirSync(dir);
            files.forEach(file => {
                const filePath = path.join(dir, file);
                if (fs.statSync(filePath).isDirectory()) {
                    countFiles(filePath);
                } else {
                    fileCount++;
                }
            });
        };
        countFiles(REMOTE_PATH);
        
        console.log(`📊 统计: ${fileCount} 个文件 → 1 个 ZIP`);
        console.log('🎉 请将 remote.zip 上传到资源服务器');
    });
    
    archive.on('error', (err) => {
        console.error('❌ 打包失败:', err);
        process.exit(1);
    });
    
    archive.on('warning', (err) => {
        if (err.code === 'ENOENT') {
            console.warn('⚠️ 警告:', err);
        } else {
            throw err;
        }
    });
    
    // 连接输出流
    archive.pipe(output);
    
    // 添加 remote 目录内容（不包含 remote 目录本身）
    archive.directory(REMOTE_PATH, false);
    
    // 完成打包
    await archive.finalize();
}

// 生成版本信息文件
function generateVersionInfo() {
    const versionInfo = {
        version: '1.0.0',
        buildTime: new Date().toISOString(),
        zipHash: '' // 可选：计算 ZIP 的 MD5
    };
    
    const versionPath = path.join(REMOTE_PATH, 'version.json');
    fs.writeFileSync(versionPath, JSON.stringify(versionInfo, null, 2));
    console.log('📝 版本信息已生成:', versionPath);
}

// 主函数
async function main() {
    try {
        generateVersionInfo();
        await buildZip();
```

## 六、风险评估

### 6.1 低风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| ZIP 下载失败 | 无法进入游戏 | 自动回退到原有逻辑 |
| 解压失败 | 无法进入游戏 | 清除缓存重新下载 |
| 本地存储空间不足 | 无法缓存 | 检测可用空间，提示用户 |

### 6.2 回退方案

如果 ZIP 预加载失败，自动回退到原有的远程加载逻辑：

```typescript
try {
    await this.preloadWithZip();
} catch (error) {
    console.warn('[PreloadManager] ZIP 预加载失败，回退到远程加载');
    await this.preloadWithRemote();
}
```

### 6.3 兼容性

| 环境 | 行为 |
|------|------|
| 微信小游戏 | 使用 ZIP 预下载 |
| 浏览器/预览 | 使用原有远程加载 |
| 其他小游戏平台 | 需单独适配 |
