# 微信小游戏429并发问题综合修复方案（010-020合并版）

## 问题概述
微信小游戏环境下，Asset Bundle加载时频繁触发429错误（"Too Many Requests"），导致资源加载失败、用户体验差。经过多轮深度调查和修复尝试（010-020），最终通过**Bundle合并+优化加载策略**大幅缓解问题，但尚未完全根治。

## 根本原因分析

### 1. 微信官方限制
- **并发上限**：`wx.request`、`wx.uploadFile`、`wx.downloadFile` 总并发上限为 **10个**
- **超出行为**：超过10个请求会排队，服务器可能返回429拒绝
- **Bundle影响**：单个Asset Bundle可能触发多个`wx.downloadFile`请求

### 2. 架构层面问题
- **多Bundle并发**：原有6个Bundle（bg、title、tiles、slot、words、modal）同时加载
- **场景切换爆发**：Loading→MainMenu→Game场景切换时集中爆发请求
- **缓存复用不足**：各模块独立加载，未充分利用已缓存资源
- **底层API泄漏**：Cocos引擎底层可能绕过应用层并发控制

### 3. 复杂度分析
- **HTTP请求数量**：5个Bundle × 3-4个文件/Bundle = 15-20个并发请求
- **时间集中度**：场景切换时1-2秒内集中发起
- **真机敏感性**：真机环境比开发者工具更严格

## 修复历程（010-020）

### 阶段一：并发控制与重试机制（010-012）
**思路**：在应用层实现并发控制和429重试机制
- **PreloadManager并发控制**：限制最大并发数为3，微信环境强制串行加载
- **429自动重试**：检测到429错误时延迟重试，带随机抖动防止雪崩
- **场景预加载**：在Loading场景预加载主菜单Bundle，避免场景切换时爆发

**结果**：部分缓解，但429错误仍持续存在

### 阶段二：底层API拦截（013-016）
**思路**：在游戏启动最早期劫持微信原生网络API
- **WXNetworkGate拦截器**：劫持`wx.request`和`wx.downloadFile`，建立全局队列控制
- **熔断机制**：检测到429时全局暂停2秒，让服务器"冷静"
- **流量整形**：强制100ms请求间隔，物理限制QPS

**结果**：显著改善，但拦截器与Cocos引擎存在兼容性问题

### 阶段三：兼容性修复（017-018）
**思路**：解决微信小游戏环境兼容性问题
- **Base64解码修复**：解决BloomFilter在微信环境的`atob`未定义问题
- **AbortController Polyfill**：为微信小游戏提供AbortController实现
- **内存监控**：添加内存警告监控和主动GC

**结果**：兼容性问题解决，但429根本原因未解决

### 阶段四：Bundle合并策略（019-020）
**思路**：从架构层面减少HTTP请求数量
- **Bundle合并**：将6个独立Bundle合并为1个大型Bundle
- **单Bundle加载**：Loading阶段只加载1个Bundle，大幅减少并发
- **缓存优先**：所有模块优先使用已缓存资源，避免重复请求

**结果**：**大幅改善**，429错误频率显著降低，但仍未完全根治

## 最终解决方案：Bundle合并+优化加载

### 核心策略
1. **Bundle合并**：6个Bundle → 1个Bundle，HTTP请求从15-20个降到3-5个
2. **统一加载入口**：所有模块通过PreloadManager加载，避免重复请求
3. **缓存优先策略**：优先使用已缓存资源，减少网络请求
4. **场景预加载**：关键场景切换前预加载所需资源

```javascript
const fs = require('fs');
const path = require('path');
const JSZip = require('jszip');

// 需要zip化的bundle列表
const BUNDLES_TO_ZIP = ['bg', 'title', 'tiles', 'slot', 'words', 'modal'];

async function zipBundles(buildPath) {
  const remotePath = path.join(buildPath, 'remote');
  if (!fs.existsSync(remotePath)) return;

  console.log('[ZIP] 开始压缩bundles...');
  
  for (const bundleName of BUNDLES_TO_ZIP) {
    const bundlePath = path.join(remotePath, bundleName);
    if (!fs.existsSync(bundlePath)) continue;

    console.log(`[ZIP] 压缩 ${bundleName}...`);
    const zip = new JSZip();
    
    // 递归添加文件
    function addFiles(dir, zipFolder) {
      const files = fs.readdirSync(dir);
      files.forEach(file => {
        const filePath = path.join(dir, file);
        const stat = fs.statSync(filePath);
        if (stat.isDirectory()) {
          addFiles(filePath, zipFolder.folder(file));
        } else {
          // 只压缩文本文件(JSON/config), 图片保持原样(已压缩)
          if (file.endsWith('.json') || file.endsWith('.js')) {
            zipFolder.file(file, fs.readFileSync(filePath), { 
              compression: 'DEFLATE', 
              compressionOptions: { level: 9 } 
            });
          } else {
            zipFolder.file(file, fs.readFileSync(filePath), { compression: 'STORE' });
          }
        }
      });
    }
    
    addFiles(bundlePath, zip);
    
    // 生成zip文件
    const zipContent = await zip.generateAsync({ type: 'nodebuffer' });
    fs.writeFileSync(path.join(remotePath, `${bundleName}.zip`), zipContent);
    
    console.log(`[ZIP] ${bundleName}.zip 生成完成 (${(zipContent.length / 1024).toFixed(2)}KB)`);
  }
  
  console.log('[ZIP] 所有bundle压缩完成');
}

module.exports = { zipBundles };
```

```typescript
import { _decorator, assetManager } from 'cc';

const { ccclass } = _decorator;

@ccclass('ZipResourceManager')
export class ZipResourceManager {
  private static _instance: ZipResourceManager = null;
  private zipCache: Map<string, { path?: string; zip?: any }> = new Map();
  private fileCache: Map<string, any> = new Map();

  public static getInstance(): ZipResourceManager {
    if (!ZipResourceManager._instance) {
      ZipResourceManager._instance = new ZipResourceManager();
    }
    return ZipResourceManager._instance;
  }

  /**
   * 下载并解压ZIP包
   */
  public async loadAndUnzip(bundleName: string): Promise<void> {
    if (this.zipCache.has(bundleName)) {
      console.log(`[ZipResourceManager] ${bundleName} 已缓存`);
      return;
    }

    return new Promise((resolve, reject) => {
      const remoteUrl = assetManager.downloader['remoteServerAddress'] || '';
      const zipUrl = `${remoteUrl}remote/${bundleName}.zip`;

      console.log(`[ZipResourceManager] 开始下载 ${zipUrl}`);

      if (typeof wx !== 'undefined') {
        // 微信环境
        const downloadTask = wx.downloadFile({
          url: zipUrl,
          success: (res) => {
            if (res.statusCode === 200) {
              this.unzipWeChat(bundleName, res.tempFilePath, resolve, reject);
            } else {
              reject(new Error(`下载失败: ${res.statusCode}`));
            }
          },
          fail: reject
        });

        downloadTask.onProgressUpdate((res) => {
          console.log(`[ZipResourceManager] ${bundleName} 下载进度: ${res.progress}%`);
        });
      } else {
        // 浏览器环境
        fetch(zipUrl)
          .then(res => res.arrayBuffer())
          .then(buffer => this.unzipBrowser(bundleName, buffer))
          .then(() => resolve())
          .catch(reject);
      }
    });
  }

  private unzipWeChat(bundleName: string, tempFilePath: string, resolve: () => void, reject: (err: any) => void): void {
    const fs = wx.getFileSystemManager();
    const targetPath = `${wx.env.USER_DATA_PATH}/${bundleName}`;

    fs.unzip({
      zipFilePath: tempFilePath,
      targetPath: targetPath,
      success: () => {
        console.log(`[ZipResourceManager] ${bundleName} 解压成功`);
        this.zipCache.set(bundleName, { path: targetPath });
        resolve();
      },
      fail: reject
    });
  }

  private async unzipBrowser(bundleName: string, buffer: ArrayBuffer): Promise<void> {
    const JSZip = window['JSZip'];
    const zip = await JSZip.loadAsync(buffer);
    this.zipCache.set(bundleName, { zip });
    console.log(`[ZipResourceManager] ${bundleName} 解压成功`);
  }

  /**
   * 从ZIP中加载文件
   */
  public async loadFileFromZip(bundleName: string, filePath: string): Promise<any> {
    const cacheKey = `${bundleName}:${filePath}`;
    if (this.fileCache.has(cacheKey)) {
      return this.fileCache.get(cacheKey);
    }

    const zipInfo = this.zipCache.get(bundleName);
    if (!zipInfo) {
      throw new Error(`Bundle ${bundleName} 未加载`);
    }

    if (typeof wx !== 'undefined') {
      // 微信环境: 从文件系统读取
      const fs = wx.getFileSystemManager();
      const fullPath = `${zipInfo.path}/${filePath}`;

      return new Promise((resolve, reject) => {
        fs.readFile({
          filePath: fullPath,
          encoding: 'utf8',
          success: (res) => {
            const data = JSON.parse(res.data);
            this.fileCache.set(cacheKey, data);
            resolve(data);
          },
          fail: reject
        });
      });
    } else {
      // 浏览器环境: 从JSZip对象读取
      const file = zipInfo.zip.file(filePath);
      if (!file) {
        throw new Error(`文件不存在: ${filePath}`);
      }

      const content = await file.async('text');
      const data = JSON.parse(content);
      this.fileCache.set(cacheKey, data);
      return data;
    }
  }

  /**
   * 检查ZIP是否已加载
   */
  public isZipLoaded(bundleName: string): boolean {
    return this.zipCache.has(bundleName);
  }
}
```

### 三、创建XHRInterceptor

新建 `src/cocos/assets/scripts/core/XHRInterceptor.ts`:

```typescript
import { ZipResourceManager } from './ZipResourceManager';

/**
 * 拦截XMLHttpRequest, 优先从ZIP读取资源
 */
export function setupXHRInterceptor(): void {
  if (typeof XMLHttpRequest === 'undefined') return;

  const zipManager = ZipResourceManager.getInstance();
  const originalOpen = XMLHttpRequest.prototype.open;
  const originalSend = XMLHttpRequest.prototype.send;

  // 拦截open
  XMLHttpRequest.prototype.open = function(method: string, url: string, ...args: any[]) {
    // 检查是否是资源请求
    if (url.includes('/remote/')) {
      const match = url.match(/\/remote\/([^\/]+)\/(.*)/);
      if (match) {
        const bundleName = match[1];
        const filePath = match[2];
        
        if (zipManager.isZipLoaded(bundleName)) {
          (this as any)._zipResource = { bundleName, filePath, url };
        }
      }
    }
    
    return originalOpen.apply(this, [method, url, ...args]);
  };

  // 拦截send
  XMLHttpRequest.prototype.send = function(...args: any[]) {
    const zipResource = (this as any)._zipResource;
    
    if (zipResource) {
      const { bundleName, filePath } = zipResource;
      
      zipManager.loadFileFromZip(bundleName, filePath)
        .then(data => {
          // 模拟XHR响应
          Object.defineProperty(this, 'response', { value: data, writable: false });
          Object.defineProperty(this, 'status', { value: 200, writable: false });
          Object.defineProperty(this, 'readyState', { value: 4, writable: false });
          
          if (this.onload) {
            this.onload({ target: this } as any);
          }
        })
        .catch(err => {
          console.warn(`[XHRInterceptor] ZIP加载失败, 回退到网络:`, err);
          originalSend.apply(this, args);
        });
    } else {
      originalSend.apply(this, args);
    }
  };
}
```

```typescript
/**
 * 🚀 终极优化: ZIP包预加载(根治429)
 * 将多个bundle打包成zip, 大幅减少HTTP请求
 */
public async preloadZipBundles(): Promise<void> {
  this.reportProgress(0, '正在初始化ZIP资源加载...');
  
  const zipManager = ZipResourceManager.getInstance();
  const bundles = ['bg', 'title', 'tiles', 'slot', 'words'];
  
  // 微信环境: 并行下载zip(5个请求 < 10限制)
  if (typeof wx !== 'undefined') {
    console.log('[PreloadManager] 📱 微信环境: 并行下载ZIP包');
    
    let completed = 0;
    const promises = bundles.map(name => 
      zipManager.loadAndUnzip(name).then(() => {
        completed++;
        this.reportProgress(completed / bundles.length, `已加载 ${completed}/${bundles.length} 个资源包`);
      })
    );
    
    await Promise.all(promises);
  } else {
    // 浏览器: 串行加载
    console.log('[PreloadManager] 🌐 浏览器环境: 串行加载ZIP包');
    for (let i = 0; i < bundles.length; i++) {
      await zipManager.loadAndUnzip(bundles[i]);
      this.reportProgress((i + 1) / bundles.length, `已加载 ${i + 1}/${bundles.length} 个资源包`);
    }
  }
  
  this.reportProgress(0.8, 'ZIP资源加载完成');
}
```

#### 1. 扩展 PreloadManager，增加缓存优先的 bundle 加载方法

在 `PreloadManager` 中添加新方法：

```typescript
/**
 * 确保 Bundle 已加载（缓存优先，使用队列控制）
 * @param bundleName Bundle 名称
 * @returns 已加载的 Bundle 实例
 */
public async ensureBundleLoaded(bundleName: string): Promise<assetManager.Bundle> {
    // 1. 先检查官方缓存
    const cached = assetManager.getBundle(bundleName);
    if (cached) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 已缓存，直接返回`);
        return cached;
    }
    
    // 2. 检查自维护的 Map（向后兼容）
    const localBundle = this.loadedBundles.get(bundleName);
    if (localBundle) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 在本地 Map 中，直接返回`);
        return localBundle;
    }
    
    // 3. 使用队列加载（复用现有的并发控制）
    console.log(`[PreloadManager] Bundle '${bundleName}' 未缓存，开始加载...`);
    return this.loadBundleWithQueue(bundleName);
}

/**
 * 使用队列控制加载 Bundle（内部方法）
 */
private async loadBundleWithQueue(bundleName: string): Promise<assetManager.Bundle> {
    return new Promise((resolve, reject) => {
        const task = async () => {
            try {
                // 等待直到有可用的下载槽位
                while (this.activeDownloads >= this.MAX_CONCURRENT_DOWNLOADS) {
                    await new Promise(wait => setTimeout(wait, 100));
                }
                
                this.activeDownloads++;
                
                assetManager.loadBundle(bundleName, (err, bundle) => {
                    this.activeDownloads--;
                    
                    if (err) {
                        console.error(`[PreloadManager] Bundle '${bundleName}' 加载失败:`, err);
                        reject(err);
                    } else {
                        console.log(`[PreloadManager] Bundle '${bundleName}' 加载成功`);
                        this.loadedBundles.set(bundleName, bundle);
                        resolve(bundle);
                    }
                    
                    // 处理队列中的下一个任务
                    if (this.downloadQueue.length > 0) {
                        const nextTask = this.downloadQueue.shift();
                        if (nextTask) {
                            nextTask().catch(console.error);
                        }
                    }
                });
            } catch (error) {
                this.activeDownloads--;
                reject(error);
            }
        };
        
        // 添加到队列
        if (this.activeDownloads >= this.MAX_CONCURRENT_DOWNLOADS) {
            this.downloadQueue.push(task);
        } else {
            task().catch(console.error);
        }
    });
}
```

```typescript
private async loadCoreDict(): Promise<void> {
    try {
        // 使用 PreloadManager 确保 words Bundle 已加载
        const preloadManager = PreloadManager.getInstance();

private async loadExtendedDict(): Promise<void> {
    try {
        // 使用 PreloadManager 确保 words Bundle 已加载
        const preloadManager = PreloadManager.getInstance();
        const bundle = await preloadManager.ensureBundleLoaded('words');
        
        // 加载扩展词库

            bundle.load('words_extended', JsonAsset, (wordsErr, wordsAsset) => {

                            const words = jsonData.by_len[len];
                            if (Array.isArray(words)) {
                                words.forEach((word: string) => {
                                    this.extendedDict.add(word.toUpperCase());
                                });
                            }
                        }
                    }
                }
                
                // 加载扩展词库释义
                bundle.load('zh_gloss_extended', JsonAsset, (glossErr, glossAsset) => {
                    if (!glossErr && glossAsset && glossAsset.json) {

                                if (!this.coreDict.has(word.toUpperCase())) {
                                    this.coreDict.set(word.toUpperCase(), definition);
                                }
                            }
                        }
                    }
                    resolve();
                });
            });
        });
```
