## 问题清单与根因分析

### 问题1：卡片需要双击才能飞到牌槽

#### 现象描述
- 用户点击可点击态卡片后，卡片没有立即飞向牌槽
- 需要点击第二次才会触发飞行动画

#### 根因分析

通过代码分析，发现**事件监听器重复注册**问题：

**StackBoard.ts（第106-108行）**：
```typescript
// ❌ 错误：在createTileNode中注册点击事件
tileNode.on(Node.EventType.TOUCH_END, () => {
    this.onTileClick(card.id);
}, this);
```

**LetterTile.ts（第171行）**：
```typescript
// ❌ 错误：LetterTile组件内部也注册了TOUCH_END事件
this.node.on(Node.EventType.TOUCH_START, this.onTouchStart, this);
this.node.on(Node.EventType.TOUCH_END, this.onTouchEnd, this);
this.node.on(Node.EventType.TOUCH_CANCEL, this.onTouchCancel, this);
```

**LetterTile.ts（第187-193行）**：
```typescript
private onTouchEnd(_event: EventTouch): void {
    if (this.currentState === 'selectable' || this.currentState === 'highlight') {
        this.updateVisual(); // 恢复正常颜色
        // ❌ 发射自定义事件，但StackBoard没有监听这个事件！
        this.node.emit('tile:clicked', this);
    }
}
```

**核心矛盾**：
1. StackBoard在节点上监听`TOUCH_END`事件，回调`onTileClick()`
2. LetterTile组件内部也监听`TOUCH_END`，但回调`onTouchEnd()`发射`tile:clicked`事件
3. StackBoard并没有监听`tile:clicked`事件！
4. 两个监听器互相干扰，导致事件冒泡异常

**为什么需要双击**：
- 第一次点击：LetterTile的`onTouchEnd`先执行，消费了事件
- 第二次点击：StackBoard的监听器才被触发

### 问题2：单词闪烁动画不出现

#### 现象描述
- 当牌槽中检测到有效单词时，单词没有闪烁效果
- 按钮组（"✓消除"和"⏭继续拼"）没有显示

#### 根因分析

**SlotQueue.ts（第256-275行）- highlightMatchedLetters方法**：

```typescript
private highlightMatchedLetters(match: WordMatch): void {
    for (let i = 0; i < this.slotNodes.length; i++) {
        const slotNode = this.slotNodes[i];
        if (!slotNode) continue;

        const tile = slotNode.getComponent(LetterTile);
        if (!tile) continue;

        if (i >= match.startIdx && i <= match.endIdx) {
            // ✅ 设置状态为correct
            tile.setState('correct');

            // ❌ 问题：闪烁动画只作用于slotNode节点
            this.playBlinkAnimation(slotNode);
        } else {
            tile.setState('highlight');
        }
    }
}
```

**SlotQueue.ts（第280-287行）- playBlinkAnimation方法**：

```typescript
private playBlinkAnimation(node: Node): void {
    // ❌ 严重问题：动画作用在slot节点上，而非字母卡片！
    tween(node)
        .to(0.3, { scale: new Vec3(1.1, 1.1, 1) })
        .to(0.3, { scale: new Vec3(1, 1, 1) })
        .union()
        .repeatForever()  // ⚠️ 永久循环，没有停止条件
        .start();
}
```

**核心问题**：

1. **动画目标错误**：
   - `playBlinkAnimation(slotNode)` 缩放的是slotItem预制体的**根节点**
   - 但字母牌节点是作为slot的**子节点**存在的
   - 缩放父节点不会产生明显的视觉效果

2. **动画无限循环**：
   - `repeatForever()` 导致动画永久循环
   - 即使调用`stopBlink()`也无法停止（没有调用`Tween.stopAllByTarget()`）

3. **状态切换不明显**：
   - `tile.setState('correct')` 只是换了一张SpriteFrame
   - 没有颜色闪烁、透明度变化等视觉冲击

**核心问题**：

2. **updateUI()逻辑错误**：

**SlotQueue.ts（第376-421行）- updateUI方法**：

```typescript
private updateUI(): void {
    const letters = this.slotManager.getLetters();

    // 确保有足够的slot节点
    if (this.slotNodes.length === 0) {
        this.createSlotNodes();
    }

    // ❌ 问题：遍历所有slotNodes，不管有没有字母
    for (let i = 0; i < this.slotNodes.length; i++) {
        const slotNode = this.slotNodes[i];
        if (!slotNode || !slotNode.isValid) continue;

        const tile = slotNode.getComponent(LetterTile);

        if (i < letters.length) {
            // ✅ 有字母：显示字母
            if (tile) {
                tile.setChar(letters[i]);
                tile.setState('highlight');
                if (tile.charLabel) {
                    tile.charLabel.string = letters[i].toUpperCase();
                }
            }
        } else {
            // ❌ 问题：无字母时，直接清空字母标签
            if (tile && tile.charLabel) {
                tile.charLabel.string = ''; // 清空字母
            }

            // ❌ 问题：试图恢复slot背景图，但会破坏飞过来的字母节点
            const backgroundNode = slotNode.getChildByName('Background');
            if (backgroundNode && this.slotBackgroundFrame) {
                const sprite = backgroundNode.getComponent(Sprite);
                if (sprite) {
                    sprite.spriteFrame = this.slotBackgroundFrame;
                    console.log(`[SlotQueue] 🔄 恢复slot[${i}]背景图`);
                }
            }
        }
    }
}
```

**为什么牌槽被清空**：

当`removeWord()`异步完成后，调用`this.slotManager.removeWord(match)`，这会从字母数组中移除匹配的字母。

例如：
```
消除前：letters = ['C', 'A', 'T', 'S']  (牌槽中有4个字母)
匹配单词：CAT (startIdx=0, endIdx=2)
消除后：slotManager.removeWord() 移除索引0-2 → letters = ['S']

updateUI()遍历：
- i=0: letters[0] = 'S' ✅ 显示S
- i=1: letters[1] = undefined ❌ 清空字母
- i=2: letters[2] = undefined ❌ 清空字母
- i=3: letters[3] = undefined ❌ 清空字母
```

**但这是正确的逻辑！**

真正的问题在于：**设计文档中描述的"牌槽应该保留下来"是否正确？**

根据设计文档第2.2章节（牌槽机制）：
- 牌槽是用来暂存字母的
- 消除单词后，**被消除的字母应该从牌槽中移除**
- **剩余的字母应该保留在牌槽中**

所以，当前实现是**正确的**！

用户描述的"牌槽跟着一起被清除了"，可能误解了游戏机制。

**需要确认**：
- 牌槽中只有匹配的字母被清除？还是所有字母都被清除？
- 如果所有字母都被清除，是`slotManager.removeWord()`的逻辑错误

### 修复2：单词闪烁动画重构

#### 文件：SlotQueue.ts

**修改位置**：第256-275行（highlightMatchedLetters方法）

```typescript
private highlightMatchedLetters(match: WordMatch): void {
    console.log(`[SlotQueue] highlightMatchedLetters, match:`, match);

    for (let i = 0; i < this.slotNodes.length; i++) {
        const slotNode = this.slotNodes[i];
        if (!slotNode) continue;

        // ✅ 修复：查找字母牌节点（LetterTile组件所在节点）
        const letterTileNode = this.findLetterTileNode(slotNode);
        if (!letterTileNode) {
            console.warn(`[SlotQueue] slot[${i}]中未找到LetterTile节点`);
            continue;
        }

        const tile = letterTileNode.getComponent(LetterTile);
        if (!tile) continue;

        if (i >= match.startIdx && i <= match.endIdx) {
            // 匹配的字母：设置为correct状态
            tile.setState('correct');

            // ✅ 修复：闪烁动画作用于字母牌节点
            this.playBlinkAnimation(letterTileNode, match.word);

            console.log(`[SlotQueue] slot[${i}]闪烁动画已启动`);
        } else {
            // 未匹配的字母：保持高亮
            tile.setState('highlight');
        }
    }
}

/**
 * ✅ 新增：查找slot节点中的字母牌节点
 * 因为addLetter时，字母牌节点被setParent到slot下
 */
private findLetterTileNode(slotNode: Node): Node | null {
    // 遍历slot的所有子节点，找到LetterTile组件
    for (const child of slotNode.children) {
        const tile = child.getComponent(LetterTile);
        if (tile) {
            return child;
        }
    }
    return null;
}
```

**修改位置**：第280-287行（playBlinkAnimation方法）

```typescript
/**
 * 播放闪烁动画（重构版）
 * ✅ 修复：
 * 1. 作用于字母牌节点，而非slot根节点
 * 2. 使用tag标记，方便后续停止
 * 3. 不再使用repeatForever，改为有限次数
 */
private playBlinkAnimation(letterTileNode: Node, word: string): void {
    // ⚠️ 停止该节点上所有之前的闪烁动画
    Tween.stopAllByTarget(letterTileNode);

    // 闪烁效果：缩放+透明度变化
    tween(letterTileNode)
        .tag(1001) // 标记为闪烁动画
        // 第1次闪烁
        .to(0.15, { scale: new Vec3(1.15, 1.15, 1) })
        .to(0.15, { scale: new Vec3(1, 1, 1) })
        // 第2次闪烁
        .to(0.15, { scale: new Vec3(1.15, 1.15, 1) })
        .to(0.15, { scale: new Vec3(1, 1, 1) })
        // 第3次闪烁
        .to(0.15, { scale: new Vec3(1.15, 1.15, 1) })
        .to(0.15, { scale: new Vec3(1, 1, 1) })
        // 第4次闪烁
        .to(0.15, { scale: new Vec3(1.15, 1.15, 1) })
        .to(0.15, { scale: new Vec3(1, 1, 1) })
        // 第5次闪烁
        .to(0.15, { scale: new Vec3(1.15, 1.15, 1) })
        .to(0.15, { scale: new Vec3(1, 1, 1) })
        .call(() => {
            console.log(`[SlotQueue] 闪烁动画完成（5次循环）: ${word}`);
        })
        .start();
}
```

**修改位置**：第229-251行（stopBlink方法）

```typescript
public stopBlink(): void {
    console.log('[SlotQueue] stopBlink调用');

    this.blinking = false;
    this.blinkTimer = 0;

    // 隐藏按钮组
    if (this.blinkGroup) {
        this.blinkGroup.active = false;
    }

    // ✅ 修复：停止所有闪烁动画并恢复状态
    for (let i = 0; i < this.slotNodes.length; i++) {
        const slotNode = this.slotNodes[i];
        if (!slotNode) continue;

        // 查找字母牌节点
        const letterTileNode = this.findLetterTileNode(slotNode);
        if (!letterTileNode) continue;

        // 停止闪烁动画
        Tween.stopAllByTag(1001, letterTileNode);

        // 恢复节点缩放
        letterTileNode.setScale(1, 1, 1);

        const tile = letterTileNode.getComponent(LetterTile);
        if (tile) {
```

```typescript
private async playRemoveAnimation(match: WordMatch): Promise<void> {
    console.log(`[SlotQueue] 播放消除动画: ${match.word}, 索引${match.startIdx}-${match.endIdx}`);

    const promises: Promise<void>[] = [];

    for (let i = match.startIdx; i <= match.endIdx; i++) {
        const slotNode = this.slotNodes[i];
        if (!slotNode) continue;

        // ✅ 修复：对字母牌节点播放动画
        const letterTileNode = this.findLetterTileNode(slotNode);
        if (!letterTileNode) {
            console.warn(`[SlotQueue] slot[${i}]中未找到LetterTile节点`);
            continue;
        }

        console.log(`[SlotQueue] 消除动画：slot[${i}]`);

        const promise = new Promise<void>((resolve) => {
            tween(letterTileNode)
                .to(0.2, { scale: new Vec3(1.3, 1.3, 1) })  // 放大
                .to(0.3, { scale: new Vec3(0, 0, 1) })      // 缩小至消失
                .call(() => {
                    console.log(`[SlotQueue] slot[${i}]消除完成`);

                    // ✅ 销毁字母牌节点
                    if (letterTileNode.isValid) {
                        letterTileNode.destroy();
                    }

                    resolve();
                })
                .start();
        });

        promises.push(promise);
    }

    await Promise.all(promises);
    console.log('[SlotQueue] 所有消除动画完成');
}
```

**预期效果**：
- 倒计时日志清晰显示剩余时间

## 风险评估与降级方案

### 风险1：闪烁动画性能问题

**风险描述**：
- 多个字母同时闪烁（如7-8个字母的单词）
- 可能导致帧率下降

**降级方案**：
```typescript
// 如果性能不佳，降低闪烁频率
.to(0.2, { scale: new Vec3(1.1, 1.1, 1) })  // 降低缩放倍数
.to(0.2, { scale: new Vec3(1, 1, 1) })      // 延长动画时长
```

---

### 风险2：字母牌节点查找失败

**风险描述**：
- `findLetterTileNode()`可能找不到LetterTile节点
- 导致闪烁动画不播放

**降级方案**：
```typescript
// 在addLetter时，给字母牌节点打标签
letterTileNode.name = `LetterTile_${slotIndex}`;

// 查找时优先按名字查找
private findLetterTileNode(slotNode: Node): Node | null {
    const child = slotNode.getChildByName(/^LetterTile_/);
    if (child) return child;

    // 降级：遍历查找LetterTile组件
    for (const child of slotNode.children) {
        if (child.getComponent(LetterTile)) return child;
    }
    return null;
}
```

---

### 风险3：按钮未绑定导致无法消除

**风险描述**：
- 如果场景中`confirmButton`或`continueButton`未绑定
- 游戏将无法手动消除单词

**降级方案**：
```typescript
// 在onLoad()中添加强制检查
if (!this.confirmButton || !this.continueButton || !this.blinkGroup) {
```
