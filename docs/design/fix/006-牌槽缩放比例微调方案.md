# 006 - 牌槽缩放比例微调方案

## 文档信息

- **创建日期**: 2025-10-19
- **问题来源**: 005方案实施后，牌槽仍然超出屏幕（已去除spacing）
- **影响范围**: SlotQueue.ts 的 `getSlotScale()` 方法
- **优先级**: 🟡 **P1（微调，快速修复）**
- **方案类型**: 纯调整方案（仅修改缩放系数）

---

## 问题分析

### 1. 当前状态（005方案实施后）

**已实现的缩放档位**：
```typescript
private getSlotScale(capacity: number): number {
    if (capacity <= 7) {
        return 1.0;    // 100%（初始状态）
    } else if (capacity === 8) {
        return 0.875;  // 87.5%（第一次扩容）
    } else {
        return 0.71;   // 71%（9-10格，统一缩放）
    }
}
```

**已实现的布局逻辑**：
```typescript
private layoutSlotsWithPureMath(): void {
    const capacity = this.slotNodes.length;
    const scale = this.getSlotScale(capacity);

    // 动态计算slot宽度
    const baseSlotWidth = 97; // 7格时的基准宽度（680/7 ≈ 97px）
    const slotWidth = baseSlotWidth * scale;

    const totalWidth = slotWidth * capacity;
    const startX = -totalWidth / 2 + slotWidth / 2;
    // ...
}
```

### 2. 问题现象

**用户反馈**：
> "每加一个牌槽后，还是有点大，已经超出了屏幕，我已经把layout布局的space给去掉了"

**实际计算（当前缩放比例）**：

| 容量 | 缩放比例 | slot宽度 | 总宽度 | 是否超出680px |
|------|---------|---------|--------|-------------|
| 7格 | 1.0 | 97px | 679px | ✅ 未超出 |
| 8格 | 0.875 | 84.9px | 679px | ✅ 未超出 |
| 9格 | 0.71 | 68.9px | **620px** | ✅ 未超出（实际有余量） |
| 10格 | 0.71 | 68.9px | **689px** | ❌ **超出9px！** |

**问题根源**：
- **10格时总宽度 = 68.9 × 10 = 689px > 680px**
- 虽然9格时没问题（620px），但10格时确实超出了
- **71%的缩放比例对于10格来说不够激进**

## 调整方案

### 1. 核心思路

**目标**：确保10格时总宽度 ≤ 680px，且有一定余量（5-10px）

**策略**：采用**更激进的四档式缩放**，而非原来的三档式

**关键变化**：
1. **8格缩放比例更激进**：87.5% → **85%**
2. **9格单独一档**：71% → **75%**
3. **10格最激进**：71% → **68%**

---

### 2. 新的缩放档位表

| 容量 | 旧缩放比例 | 新缩放比例 | slot宽度（新） | 总宽度（新） | 余量 | 字母字体大小（估算） |
|------|-----------|-----------|--------------|------------|------|---------------------|
| **7格** | 1.0 | **1.0** | 97px | 679px | 1px | 36px ✅ |
| **8格** | 0.875 | **0.85** | 82.5px | 660px | 20px | 30.6px ✅ |
| **9格** | 0.71 | **0.75** | 72.75px | 655px | 25px | 27px ✅ |
| **10格** | 0.71 | **0.68** | 66px | 660px | 20px | 24.5px ✅（接近下限但可读）|

**计算逻辑**：
```
slot宽度 = 97px × 缩放比例
总宽度 = slot宽度 × 格子数量
余量 = 680px - 总宽度
```

**验证**：
- ✅ 7格：679px < 680px（余量1px）
- ✅ 8格：660px < 680px（余量20px）
- ✅ 9格：655px < 680px（余量25px）
- ✅ 10格：660px < 680px（余量20px）⭐ **关键！确保不超出！**

## 实施方案

### 1. 需要修改的代码

**文件**：`src/cocos/assets/scripts/ui/SlotQueue.ts`

**修改位置**：`getSlotScale()` 方法（Line 122-130）

**旧代码**：
```typescript

    if (capacity <= 7) {
        return 1.0;    // 100%（初始状态）

```

**新代码**：
```typescript
/**
 * 根据容量获取缩放比例（四档式，更激进）
 * @param capacity 当前容量（7-10）
 * @returns 缩放比例（1.0 / 0.85 / 0.75 / 0.68）
 */
private getSlotScale(capacity: number): number {
    if (capacity <= 7) {
        return 1.0;    // 100%（初始状态，97px/格，总宽679px）
    } else if (capacity === 8) {
        return 0.85;   // 85%（第一次扩容，82.5px/格，总宽660px）

        return 0.75;   // 75%（第二次扩容，72.75px/格，总宽655px）
    } else {
        return 0.68;   // 68%（最大容量10格，66px/格，总宽660px）

}
```

### 2. 变更说明

**关键变化**：
1. **8格**：`0.875 → 0.85`（缩小幅度+2.5%）
2. **9格**：`0.71 → 0.75`（放大幅度+5.6%，避免9格时过早缩得太小）
3. **10格**：`0.71 → 0.68`（缩小幅度-4.2%，**确保不超出屏幕**）

**兼容性**：
- ✅ 无需修改其他代码（布局逻辑、动画逻辑均自动适配）
- ✅ `layoutSlotsWithPureMath()` 方法会自动使用新的缩放比例

## 潜在风险与缓解措施

### 风险1：闪烁动画超出屏幕

**问题**：
- 10格时，slot宽度为66px
- 闪烁动画放大到1.15倍：66px × 1.15 = 75.9px
- 10格闪烁总宽度：75.9px × 10 = 759px > 680px（**超出79px！**）

**缓解措施**：
```typescript
// 方案A：限制闪烁幅度（推荐）
private playBlinkAnimation(letterTileNode: Node, word: string): void {
    // 根据当前缩放比例调整闪烁幅度
    const currentScale = this.getCurrentScale();
    const blinkScale = currentScale >= 0.7 ? 1.15 : 1.10; // 缩放≥70%时闪烁1.15倍，否则1.10倍

    tween(letterTileNode)
        .tag(1001)
        .to(0.15, { scale: new Vec3(blinkScale, blinkScale, 1) })
        // ...
}

// 方案B：仅闪烁透明度，不缩放（保守）
private playBlinkAnimation(letterTileNode: Node, word: string): void {
    const sprite = letterTileNode.getComponent(Sprite);
    if (!sprite) return;

    tween(sprite)
        .tag(1001)
        .to(0.15, { color: new Color(255, 255, 255, 200) }) // 半透明
        .to(0.15, { color: new Color(255, 255, 255, 255) }) // 完全不透明
        // 循环3次
}
```

**推荐**：方案A（调整闪烁幅度）
- 10格时闪烁1.10倍：66px × 1.10 = 72.6px，总宽726px（超出46px，仍超出但可接受）
- 或者干脆10格时不闪烁缩放，仅闪烁颜色/透明度
