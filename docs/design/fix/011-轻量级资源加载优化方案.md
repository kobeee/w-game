# 轻量级资源加载优化方案

**创建日期**: 2025-11-23
**目标问题**: Loading场景加载时间过长 + 微信小游戏429并发问题
**方案类型**: 渐进式优化（低风险、快速落地）

---

## 一、问题诊断

### 1.1 核心痛点

**痛点1：Loading时间过长（3-5秒）**
- 根源：全量预加载策略，一次性下载所有Asset Bundle
- 当前Loading阶段加载：bg、title、tiles、slot、words、modal（6个bundle）
- 玩家等待体验差，首屏加载慢

**痛点2：微信小游戏429错误频发**
- 根源：无全局协调机制，各模块独立重复下载
- 微信限制：`wx.request/downloadFile`总并发上限为10
- 实际场景：进入主玩法时，各组件同时触发`assetManager.loadBundle`，请求数达30-50个

### 1.2 现有代码问题

1. **PreloadManager仅在Loading阶段有效**
   - 有串行下载逻辑（MAX_CONCURRENT_DOWNLOADS = 3）
   - 但仅限于Loading场景，其他模块绕过它直接调用`assetManager.loadBundle`

2. **各模块重复加载**
   - GameApp、GlossSheet、StackGameApp、LocalDictionary各自独立加载words bundle
   - 即使Loading已缓存，仍重复触发网络请求

3. **无缓存优先机制**
   - 直接调用`assetManager.loadBundle`，不检查`assetManager.getBundle()`缓存
   - 导致重复下载和资源浪费

---

## 二、优化策略

### 2.1 核心原则

**原则1：按需加载**
- Loading只加载首屏必需资源（bg、title、words）
- 其他资源（tiles、slot、modal）后台静默加载
- 词库数据异步加载，不阻塞场景切换

**原则2：缓存优先**
- 所有模块必须通过统一接口加载bundle
- 先检查官方缓存 → 再检查本地Map → 最后走网络
- 避免重复下载

**原则3：全局协调**
- 所有`assetManager.loadBundle`调用通过PreloadManager
- 复用现有的并发控制队列（MAX_CONCURRENT_DOWNLOADS = 3）
- 微信环境串行加载，浏览器环境可并发

### 2.2 技术路线

**不采用ZIP化方案的原因：**
- 复杂度爆炸（+300行代码）
- 微信文件系统API兼容性风险
- 内存占用增加10-20MB
- 构建流程侵入性强

**采用轻量级方案的优势：**
- 改动量小（+50行代码）
- 风险可控，可快速回滚
- 内存无额外开销
- 1小时内完成实施

## 三、实施步骤

### 步骤1：改造PreloadManager（15分钟）

**文件**: `src/cocos/assets/scripts/app/PreloadManager.ts`

**新增方法**：

```typescript
/**
 * 确保Bundle已加载（缓存优先 + 队列控制）
 * @param bundleName Bundle名称
 * @returns 已加载的Bundle实例
 */
public async ensureBundleLoaded(bundleName: string): Promise<assetmanager.Bundle> {
    // 1. 检查官方缓存
    const cached = assetManager.getBundle(bundleName);
    if (cached) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 已缓存，直接返回`);
        return cached;
    }
    
    // 2. 检查本地Map（向后兼容）
    const localBundle = this.loadedBundles.get(bundleName);
    if (localBundle) {
        console.log(`[PreloadManager] Bundle '${bundleName}' 在本地Map中，直接返回`);
        return localBundle;
    }
    
    // 3. 使用队列加载（复用现有的并发控制）
    console.log(`[PreloadManager] Bundle '${bundleName}' 未缓存，开始加载...`);
    return this.loadBundleWithQueue(bundleName);
}

/**
 * 使用队列控制加载Bundle（内部方法）
 */
private async loadBundleWithQueue(bundleName: string): Promise<assetmanager.Bundle> {
    return new Promise((resolve, reject) => {
        const task = async () => {
            try {
                // 等待直到有可用的下载槽位
                while (this.activeDownloads >= this.MAX_CONCURRENT_DOWNLOADS) {
                    await new Promise(wait => setTimeout(wait, 100));
                }
                
                this.activeDownloads++;
                
                assetManager.loadBundle(bundleName, (err, bundle) => {
                    this.activeDownloads--;
                    
                    if (err) {
                        console.error(`[PreloadManager] Bundle '${bundleName}' 加载失败:`, err);
                        reject(err);
                    } else {
                        console.log(`[PreloadManager] Bundle '${bundleName}' 加载成功`);
                        this.loadedBundles.set(bundleName, bundle);
                        resolve(bundle);
                    }
                    
                    // 处理队列中的下一个任务
                    if (this.downloadQueue.length > 0) {
                        const nextTask = this.downloadQueue.shift();
                        if (nextTask) {
                            nextTask().catch(console.error);
                        }
                    }
                });
            } catch (error) {
                this.activeDownloads--;
                reject(error);
            }
        };
        
        // 添加到队列
        if (this.activeDownloads >= this.MAX_CONCURRENT_DOWNLOADS) {
            this.downloadQueue.push(task);
        } else {
            task().catch(console.error);
        }
    });
}
```

**关键点**：
- 三层检查：官方缓存 → 本地Map → 网络加载
- 复用现有的`MAX_CONCURRENT_DOWNLOADS`控制
- 微信环境自动串行，无需特殊判断

### 步骤2：优化LoadingScene（10分钟）

**文件**: `src/cocos/assets/scripts/app/LoadingScene.ts`

**修改`onLoad`方法**：

```typescript
protected async onLoad(): Promise<void> {
    try {
        const preloadManager = PreloadManager.getInstance();
        preloadManager.setProgressCallback((progress, message) => {
            if (this.loadingUI) {
                this.loadingUI.updateProgress(progress, message);
            }
        });

        // 1. 只加载首屏必需的bundle（3个）
        const essentialBundles = ['bg', 'title', 'words'];
        
        for (let i = 0; i < essentialBundles.length; i++) {
            await preloadManager.ensureBundleLoaded(essentialBundles[i]);
            this.loadingUI.updateProgress((i + 1) / essentialBundles.length, 
                `已加载 ${i + 1}/${essentialBundles.length} 个资源包`);
        }
        
        // 2. 词库数据异步加载（不阻塞场景切换）
        preloadManager.loadGlossDataWithProgress(0, 1, false).catch(error => {
            console.warn('[LoadingScene] 词库加载失败:', error);
        });
        
        // 3. 其他bundle后台静默加载（不等待）
        const backgroundBundles = ['tiles', 'slot', 'modal'];
        backgroundBundles.forEach(name => {
            preloadManager.ensureBundleLoaded(name).catch(error => {
                console.warn(`[LoadingScene] ${name} 后台加载失败:`, error);
            });
        });
        
        // 4. 立即跳转到主菜单
        director.loadScene('MainMenu');
        
    } catch (error) {
        console.error('[LoadingScene] 加载失败:', error);
        // 即使失败也继续，避免卡死
        director.loadScene('MainMenu');
    }
}
```

**效果**：
- Loading时间从3-5秒降至**1秒内**
- 首屏加载资源减少50%
- 其他资源后台加载，用户体验流畅

/**
 * 动态加载远程Asset Bundle资源
 */
private async loadRemoteAssets(): Promise<void> {
    try {
        const preloadManager = PreloadManager.getInstance();
        
        // 确保bg Bundle已加载（Loading阶段应该已完成）
        const bgBundle = await preloadManager.ensureBundleLoaded('bg');
        
        // 加载背景图
        const spriteFrame = await this.loadSpriteFrameFromBundle(bgBundle, 'game_scene_bg/spriteFrame');
        if (this.backgroundSprite && spriteFrame) {
            this.backgroundSprite.spriteFrame = spriteFrame;
        }
        
        // 确保words Bundle已加载
        await preloadManager.ensureBundleLoaded('words');
        
    } catch (error) {
        console.error('[GameApp] 远程资源加载失败:', error);
    }
}

private loadSpriteFrameFromBundle(bundle: assetmanager.Bundle, path: string): Promise<SpriteFrame> {
    return new Promise((resolve, reject) => {
        bundle.load(path, SpriteFrame, (err, spriteFrame) => {
            if (err) {
                reject(err);
            } else {
                resolve(spriteFrame);
            }
        });
    });
}

// 在WordValidationManager.initialize()中统一加载words bundle
public async initialize(): Promise<void> {
    // 确保words bundle只加载一次
    const preloadManager = PreloadManager.getInstance();
    await preloadManager.ensureBundleLoaded('words');
    
    // 然后并行加载各个JSON（此时bundle已在内存）
    await Promise.all([
        this.localDictionary.load(),
        loadBloomFromBundle()
    ]);
}

// LocalDictionary.loadCoreDict() 修改为复用bundle
private async loadCoreDict(): Promise<void> {
    try {
        // 使用PreloadManager确保words Bundle已加载
        const preloadManager = PreloadManager.getInstance();
        const bundle = await preloadManager.ensureBundleLoaded('words');
        
        const mergeJson = (asset?: JsonAsset | null) => {
            if (asset && asset.json) {
                for (const [word, definition] of Object.entries(asset.json)) {
                    if (typeof definition === 'string') {
                        this.coreDict.set(String(word).toUpperCase(), definition);
                    }
                }
            }
        };
        
        // 加载核心词库
        await new Promise<void>((resolve) => {
            bundle.load('zh_gloss', JsonAsset, (loadErr, asset) => {
                if (loadErr) {
                    console.warn('[LocalDictionary] 核心词库释义加载失败');
                } else {
                    mergeJson(asset);
                }
                
                // 加载自定义词库
                bundle.load('zh_gloss_custom', JsonAsset, (cusErr, cusAsset) => {
                    if (!cusErr) {
                        mergeJson(cusAsset);
                    }
                    resolve();
                });
            });
        });
    } catch (error) {
        console.warn('[LocalDictionary] 词库加载失败:', error);
    }
}

// BloomFilter.loadBloomFromBundle() 同样改造
export async function loadBloomFromBundle(): Promise<void> {
    try {
        const preloadManager = PreloadManager.getInstance();
        const bundle = await preloadManager.ensureBundleLoaded('words');
        
        return new Promise((resolve) => {
            bundle.load('bloom_filter', JsonAsset, (err, asset) => {
                if (err || !asset || !asset.json) {
                    console.warn('[BloomFilter] Bloom filter 加载失败');
                    resolve();
                    return;
                }
                
                try {
                    const data = asset.json as BloomData;
                    initializeBloom(data);
                    console.log('[BloomFilter] Bloom filter 加载成功');
                } catch (e) {
                    console.warn('[BloomFilter] Bloom filter 解析失败:', e);
                }
                resolve();
            });
        });
    } catch (error) {
        console.warn('[BloomFilter] 加载失败:', error);
    }
}

## 六、风险评估

### 6.1 风险等级：低

**优势**：
1. **向后兼容**：不修改原有API，只添加新方法
2. **可回滚**：随时移除`ensureBundleLoaded`调用，恢复原逻辑
3. **渐进式**：可分模块逐步改造，不影响其他功能
4. **零依赖**：不引入第三方库

### 6.2 潜在风险

| 风险点 | 概率 | 影响 | 应对措施 |
|--------|------|------|----------|
| 缓存判断不准确 | 低 | 中 | 增加多层检查（官方缓存+本地Map） |
| 队列加载死锁 | 极低 | 高 | 添加超时机制（5秒自动释放） |
| 后台加载影响性能 | 低 | 低 | 限制后台并发数为1 |
| 低端机内存不足 | 中 | 高 | 监控内存，超过阈值暂停后台加载 |
