# 001 - 卡片飞向牌槽动画消失问题修复

## 问题描述

**现象**：卡片飞向牌槽时，先躲到牌槽后面，然后才突然窜到牌槽前面，体验极差。

**复现**：点击任意卡片，观察飞行动画。

---

## 根本原因

**跨容器渲染层级问题**：

```
Canvas
  ├─ StackBoard (siblingIndex = 9999)
  │   └─ 飞行中的卡片 (siblingIndex = 9999) ← 在StackBoard容器内最上层
  └─ SlotQueue (siblingIndex = 9999)  ← 但如果SlotQueue的siblingIndex ≥ StackBoard
      └─ slot节点们                      则整个SlotQueue会遮挡StackBoard！
```

**问题**：
- 当前代码已提升卡片的siblingIndex到9999（[StackBoard.ts:188](../../src/cocos/assets/scripts/ui/StackBoard.ts#L188)）
- 当前代码已提升SlotQueue容器的siblingIndex到9999（[StackGameApp.ts:65](../../src/cocos/assets/scripts/app/StackGameApp.ts#L65)）
- **但两者的siblingIndex相同（都是9999）**，渲染顺序取决于场景创建顺序或默认排序
- 如果SlotQueue在StackBoard之后创建，或者场景中的默认顺序让SlotQueue排在后面，则SlotQueue会遮挡飞行中的卡片

**Cocos Creator渲染规则**：
- 同一父节点下，siblingIndex越大，越后渲染（在上层）
- 不同父节点下，递归向上比较父节点的siblingIndex

---

## 解决方案

**唯一正确的解决办法**：强制StackBoard容器的siblingIndex **大于** SlotQueue容器。

### 修改文件
**文件路径**：`src/cocos/assets/scripts/app/StackGameApp.ts`

### 修改位置
`onLoad()` 方法，第63-66行

### 修改代码

**修改前**：
```typescript
// ✅ 修复：确保SlotQueue容器始终在最上层，避免遮挡飞行中的卡片
if (this.slotQueue && this.slotQueue.node) {
    this.slotQueue.node.setSiblingIndex(9999);
}
```

**修改后**：
```typescript
// ✅ 修复：确保渲染层级正确（StackBoard > SlotQueue）
// SlotQueue在底层（9998），StackBoard在上层（9999）
// 这样飞行中的卡片就不会被SlotQueue遮挡
if (this.slotQueue && this.slotQueue.node) {
    this.slotQueue.node.setSiblingIndex(9998); // SlotQueue在底层
}
if (this.stackBoard && this.stackBoard.node) {
    this.stackBoard.node.setSiblingIndex(9999); // StackBoard在最上层
}
```

### 原理

```
Canvas (渲染顺序：从下到上)
  ├─ 其他UI节点 (siblingIndex < 9998)
  ├─ SlotQueue (siblingIndex = 9998)  ← 先渲染（底层）
  │   └─ slot节点们
  └─ StackBoard (siblingIndex = 9999)  ← 后渲染（上层）
      ├─ 普通卡片 (siblingIndex = 0-34)
      └─ 飞行中的卡片 (siblingIndex = 9999)  ← 整个容器在SlotQueue之上，完美！
```

**结果**：
- 飞行中的卡片在StackBoard容器内，siblingIndex=9999确保不被其他卡片遮挡 ✅
- StackBoard容器的siblingIndex=9999 **大于** SlotQueue容器的9998，整个StackBoard在SlotQueue之上 ✅
- 卡片飞行全程可见，无"先躲后显"问题 ✅
