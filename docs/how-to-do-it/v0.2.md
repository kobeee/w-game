## 1. 前置准备

### 1.1 项目配置检查

1. **打开项目**
   - 启动 Cocos Creator 3.8.7
   - 打开项目路径：`src/cocos/`

2. **项目设置检查**
   - 菜单栏 → `项目` → `项目设置`
   - **平台**: 微信小游戏
   - **屏幕方向**: Portrait（竖屏）
   - **设计分辨率**: 750×1334（iPhone 6/7/8标准）
   - **适配模式**: Fit Height（高度优先）

3. **TypeScript 配置**
   - 确认 `tsconfig.json` 存在
   - 严格模式已启用

   - 选中场景根节点（Canvas）

     - **RenderMode**: INTERSPERSE
     - **Design Resolution**: 750×1334
     - **Fit Height**: 勾选

   - 选中 Canvas 节点

     - **Type**: SIMPLE

## 4. 资源准备与导入

### 4.1 图片资源规格清单

> **🎉 重要更新**：经分析，字母卡片可以 **100% 复用**"小试牛刀"玩法的 `LetterTile` 预制体和相关资源！
> **总体资源复用率达到 79%**，实际仅需新增 3 张牌槽贴图。

#### ✅ 完全复用的资源（无需新增）

**从 `LetterTile` 预制体和 `tiles` Bundle 复用**：

| 资源名称 | 位置 | 原用途 | 新玩法用途 | 修改 |
|---------|------|-------|-----------|------|
| `tile_selectable.png` | `assets/bundle/tiles/` | 可选择状态 | **可点击（无遮挡）** - 白色背景 | ✅ 零修改 |
| `tile_disabled.png` | `assets/bundle/tiles/` | 禁用状态 | **被遮挡** - 灰色半透明 | ✅ 零修改 |
| `tile_highlight.png` | `assets/bundle/tiles/` | 高亮状态 | **悬浮中（飞向牌槽）** + **在牌槽中** - 黄色光晕 | ✅ 零修改 |
| `tile_correct.png` | `assets/bundle/tiles/` | 正确状态 | **闪烁（检测到单词）** - 绿色 | 建议改色为黄色 |
| `tile_wrong.png` | `assets/bundle/tiles/` | 错误状态 | 预留（暂不使用） | 预留 |
| `LetterTile.prefab` | `assets/resources/` | 字母瓦片预制体 | 字母卡片预制体 | ✅ 零修改 |
| `LetterTile.ts` | `assets/scripts/ui/` | 字母瓦片组件 | 字母卡片组件 | 仅添加状态映射 |

| `GlossSheet.ts` | `assets/scripts/ui/` | 释义浮层组件 | 单词释义弹窗 | ✅ 零修改 |

**状态映射逻辑**（在 `LetterTile.ts` 中实现）：
```typescript
// 现有的 TileState 枚举
export type TileState =
    | 'selectable'  // 可点击（无遮挡）→ tile_selectable.png
    | 'disabled'    // 被遮挡 → tile_disabled.png
    | 'highlight'   // 悬浮中 + 在牌槽中 → tile_highlight.png
    | 'correct'     // 闪烁（检测到单词）→ tile_correct.png
    | 'wrong';      // 预留（暂不使用）→ tile_wrong.png
```

#### 🆕 必需新增的资源（仅 1 张贴图 + 1个预制体！）

> **🎯 采用方案B：独立格子拼接**
> - 优势：动态扩容极其灵活，代码简洁，仅需 1 张贴图
> - 原理：每个格子是独立节点，使用 Layout 组件自动排列
> - 字母牌直接嵌入格子内部，无需单独的填充状态
> - **SlotItem需制作成预制体**，支持动态实例化扩容

**牌槽相关**（核心必需）：

| 资源名称 | 尺寸（px） | 格式 | 用途 | 设计规格 | 优先级 |
|---------|----------|------|------|---------|--------|
| `slot_item.png` | 85×85 | PNG-24 | 单个牌槽格子背景 | 圆角矩形框，描边 2px #7F8C8D，透明背景，圆角 8px | ⭐⭐⭐ 必需 |
| `SlotItem.prefab` | - | Prefab | 牌槽格子预制体 | 包含Frame(Sprite) + LetterSlot(空节点)，用于动态实例化 | ⭐⭐⭐ 必需 |

**设计规格详情**：
```yaml
slot_item.png:
  尺寸: 85×85px (比字母牌80×80大5px，留出视觉间隙)
  外观: 圆角矩形框
  描边: 2px，颜色 #7F8C8D (中灰色)
  背景: 透明
  圆角: 8px

说明:
  - 尺寸比 LetterTile (80×80) 大 5px
  - 字母牌嵌入时居中对齐，四周留出 2.5px 边距
  - 空格子显示描边框，有字母时字母牌覆盖在上方
```

**布局方案（方案B）**：
```
独立格子拼接，使用 Layout 自动排列：

[A] [T] [ ] [ ] [ ] [ ] [ ]
 ↑   ↑   ↑   ↑   ↑   ↑   ↑
独立 独立 独立 独立 独立 独立 独立
格子 格子 格子 格子 格子 格子 格子

视觉效果：
┌─────────┐
│  85×85  │  ← slot_item.png（圆角矩形框）
│ ┌─────┐ │
│ │80×80│ │  ← LetterTile（嵌入居中）
│ │  A  │ │
│ └─────┘ │
└─────────┘
```

**临时替代方案**（零资源快速验证）：
```typescript
// 用纯色Sprite代替 slot_item.png
const slotItem = new Node('SlotItem');
const sprite = slotItem.addComponent(Sprite);
sprite.type = Sprite.Type.SIMPLE;
sprite.color = new Color(127, 140, 141, 255); // #7F8C8D
const transform = slotItem.getComponent(UITransform);
transform.setContentSize(85, 85);
```

**资源总数更新**：
- ✅ 字母卡片：100% 复用 `LetterTile.prefab` (5张贴图)
- 🆕 牌槽格子：仅需 1 张 `slot_item.png` (85×85px)
- 🆕 牌槽预制体：需制作 `SlotItem.prefab`（结构简单，5分钟完成）

3. ✅ 便于后续迭代（如添加槽位编号、特效、状态指示）
4. ✅ 符合Cocos Creator最佳实践

```typescript
import { _decorator, Component, Label, Sprite, Node, SpriteFrame, tween, Vec3, Color } from 'cc';
const { ccclass, property } = _decorator;

/**
 * 字母卡片状态枚举
 */
export enum CardState {
    NORMAL = 0,      // 正常状态
    BLOCKED = 1,     // 被遮挡
    CLICKABLE = 2,   // 可点击（高亮）
    FLYING = 3,      // 飞向牌槽中
}

@ccclass('LetterCard')
export class LetterCard extends Component {
    @property(Label)
    letterLabel: Label = null!;

    @property(Sprite)
    cardSprite: Sprite = null!;

    @property(Node)
    glowEffect: Node = null!;

    @property(SpriteFrame)
    normalBg: SpriteFrame = null!;

    @property(SpriteFrame)
    highlightBg: SpriteFrame = null!;

    @property(SpriteFrame)
    blockedBg: SpriteFrame = null!;

    // 卡片数据
    public cardId: string = '';
    public letter: string = '';
    public layer: number = 0;
    public blocked: boolean = false;

    private currentState: CardState = CardState.NORMAL;

    /**
     * 初始化卡片
     */
    public init(id: string, letter: string, layer: number): void {
        this.cardId = id;
        this.letter = letter;
        this.layer = layer;

        if (this.letterLabel) {
            this.letterLabel.string = letter;
        }

        this.setState(CardState.NORMAL);
    }

    /**
     * 设置卡片状态
     */
    public setState(state: CardState): void {
        this.currentState = state;

        switch (state) {
            case CardState.NORMAL:
                this.setNormalState();
                break;
            case CardState.BLOCKED:
                this.setBlockedState();
                break;
            case CardState.CLICKABLE:
                this.setClickableState();
                break;
            case CardState.FLYING:
                this.setFlyingState();
                break;
        }
    }

    /**
     * 正常状态
     */
    private setNormalState(): void {
        if (this.cardSprite) {
            this.cardSprite.spriteFrame = this.normalBg;
            this.cardSprite.color = Color.WHITE;
        }
        if (this.glowEffect) {
            this.glowEffect.active = false;
        }
        this.node.setScale(1, 1, 1);
    }

    /**
     * 遮挡状态
     */
    private setBlockedState(): void {
        if (this.cardSprite) {
            this.cardSprite.spriteFrame = this.blockedBg;
            // 半透明灰色
            this.cardSprite.color = new Color(128, 128, 128, 128);
        }
        if (this.glowEffect) {
            this.glowEffect.active = false;
        }
        this.node.setScale(0.95, 0.95, 1);
    }

    /**
     * 可点击状态（高亮+光圈+呼吸动画）
     */
    private setClickableState(): void {
        if (this.cardSprite) {
            this.cardSprite.spriteFrame = this.highlightBg;
            this.cardSprite.color = Color.WHITE;
        }
        if (this.glowEffect) {
            this.glowEffect.active = true;
            this.startGlowBreathing();
        }
    }

    /**
     * 飞行状态
     */
    private setFlyingState(): void {
        if (this.glowEffect) {
            this.glowEffect.active = false;
        }
    }

    /**
     * 光圈呼吸动画
     */
    private startGlowBreathing(): void {
        if (!this.glowEffect) return;

        tween(this.glowEffect)
            .to(0.5, { scale: new Vec3(1.1, 1.1, 1) })
            .to(0.5, { scale: new Vec3(1.0, 1.0, 1) })
            .union()
            .repeatForever()
            .start();
    }

    /**
     * 飞向目标位置
     */
    public flyToPosition(targetPos: Vec3, duration: number = 0.3): Promise<void> {
        return new Promise((resolve) => {
            this.setState(CardState.FLYING);

            tween(this.node)
                .to(duration, { position: targetPos }, { easing: 'cubicOut' })
                .call(() => {
                    resolve();
                })
                .start();
        });
    }

    /**
     * 销毁卡片（带动画）
     */
    public destroyWithAnimation(): Promise<void> {
        return new Promise((resolve) => {
            tween(this.node)
                .to(0.2, { scale: new Vec3(0, 0, 0) })
                .call(() => {
                    this.node.destroy();
                    resolve();
                })
                .start();
        });
    }
}
```

```typescript
import { _decorator, Component, Node, Prefab, instantiate, Label, CCInteger } from 'cc';
const { ccclass, property } = _decorator;

@ccclass('SlotQueue')
export class SlotQueue extends Component {
    @property(Node)
    slotItemsContainer: Node = null!;

    @property(Prefab)
    slotItemPrefab: Prefab = null!;

    @property({ type: CCInteger })
    initialCapacity: number = 7;

    @property({ type: CCInteger })
    maxCapacity: number = 15;

    // 当前字母序列
    private letters: string[] = [];
    // 当前容量
    private capacity: number = 7;
    // 牌槽UI节点数组
    private slotNodes: Node[] = [];

    protected onLoad(): void {
        this.capacity = this.initialCapacity;
        this.initSlots();
    }

    /**
     * 初始化牌槽格子
     */
    private initSlots(): void {
        for (let i = 0; i < this.capacity; i++) {
            const slotNode = instantiate(this.slotItemPrefab);
            slotNode.setParent(this.slotItemsContainer);
            this.slotNodes.push(slotNode);
        }
    }

    /**
     * 添加字母到牌槽
     */
    public addLetter(letter: string): boolean {
        if (this.isFull()) {
            console.warn('牌槽已满！');
            return false;
        }

        this.letters.push(letter);
        this.updateSlotUI();
        return true;
    }

    /**
     * 移除指定范围的字母（消除单词）
     */
    public removeLetters(startIdx: number, endIdx: number): void {
        this.letters.splice(startIdx, endIdx - startIdx + 1);
        this.updateSlotUI();
    }

    /**
     * 获取当前字母序列
     */
    public getLetters(): string[] {
        return [...this.letters];
    }

    /**
     * 是否已满
     */
    public isFull(): boolean {
        return this.letters.length >= this.capacity;
    }

    /**
     * 扩容
     */
    public expand(amount: number): void {
        const oldCapacity = this.capacity;
        this.capacity = Math.min(this.capacity + amount, this.maxCapacity);

        // 动态添加格子
        for (let i = oldCapacity; i < this.capacity; i++) {
            const slotNode = instantiate(this.slotItemPrefab);
            slotNode.setParent(this.slotItemsContainer);
            this.slotNodes.push(slotNode);
        }

        console.log(`牌槽扩容: ${oldCapacity} → ${this.capacity}`);
    }

    /**
     * 更新牌槽UI显示
     */
    private updateSlotUI(): void {
        for (let i = 0; i < this.slotNodes.length; i++) {
            const slotNode = this.slotNodes[i];
            const label = slotNode.getComponentInChildren(Label);

            if (i < this.letters.length) {
                // 已填充
                if (label) {
                    label.string = this.letters[i];
                }
                slotNode.active = true;
            } else if (i < this.capacity) {
                // 空格子
                if (label) {
                    label.string = '';
                }
                slotNode.active = true;
            } else {
                // 超出容量，隐藏
                slotNode.active = false;
            }
        }
    }

    /**
     * 获取占用率
     */
    public getOccupancyRate(): number {
        return this.letters.length / this.capacity;
    }
}
```

#### 6.1.4 单词检测器（WordMatcher.ts）

```typescript
import { _decorator, Component } from 'cc';
import { WordMatch } from './StackTypes';
const { ccclass } = _decorator;

@ccclass('WordMatcher')
export class WordMatcher extends Component {
    private wordBank: Set<string> = new Set();

    /**
     * 初始化词库
     */
    public init(words: string[]): void {
        this.wordBank = new Set(words.map(w => w.toUpperCase()));
        console.log(`词库加载完成，共 ${this.wordBank.size} 个单词`);
    }

    /**
     * 查找最长匹配单词（从右向左截断）
     */
    public findWord(letters: string[]): WordMatch | null {
        const totalLen = letters.length;

        // 从完整牌槽开始，逐步去掉最左侧字母
        for (let leftCut = 0; leftCut <= totalLen - 3; leftCut++) {
            const substr = letters.slice(leftCut).join('').toUpperCase();

            if (this.wordBank.has(substr)) {
                return {
                    word: substr,
                    startIdx: leftCut,
                    endIdx: totalLen - 1,
                    length: substr.length
                };
            }

            // 剩余长度 < 3，停止检测
            if (totalLen - leftCut - 1 < 3) {
                break;
            }
        }

        return null;
    }

    /**
     * 验证单词是否有效
     */
    public isValidWord(word: string): boolean {
        return this.wordBank.has(word.toUpperCase());
    }
}
```

#### 6.1.5 堆叠棋盘管理器（StackBoard.ts）

```typescript
import { _decorator, Component, Node, Prefab, instantiate, Vec3, CCInteger } from 'cc';
import { LetterCard, CardState } from './LetterCard';
import { SlotQueue } from './SlotQueue';
import { Card } from './StackTypes';
const { ccclass, property } = _decorator;

@ccclass('StackBoard')
export class StackBoard extends Component {
    @property(Node)
    boardContainer: Node = null!;

    @property(Prefab)
    letterCardPrefab: Prefab = null!;

    @property(SlotQueue)
    slotQueue: SlotQueue = null!;

    @property({ type: CCInteger })
    cardSize: number = 80;

    @property({ type: CCInteger })
    layerSpacing: number = 20;

    // 所有卡片数据
    private cards: Card[] = [];
    // 卡片节点映射
    private cardNodes: Map<string, Node> = new Map();

    /**
     * 初始化棋盘（从布局模板）
     */
    public initFromLayout(cards: Card[]): void {
        this.cards = cards;
        this.createCardNodes();
        this.updateBlockStatus();
    }

    /**
     * 创建卡片节点
     */
    private createCardNodes(): void {
        for (const cardData of this.cards) {
            const cardNode = instantiate(this.letterCardPrefab);
            cardNode.setParent(this.boardContainer);
            cardNode.setPosition(cardData.position);

            const cardComp = cardNode.getComponent(LetterCard);
            if (cardComp) {
                cardComp.init(cardData.id, cardData.letter, cardData.layer);
            }

            // 绑定点击事件
            cardNode.on(Node.EventType.TOUCH_END, () => {
                this.onCardClick(cardData.id);
            }, this);

            this.cardNodes.set(cardData.id, cardNode);
        }
    }

    /**
     * 更新遮挡状态
     */
    private updateBlockStatus(): void {
        // 先重置所有卡片为不遮挡
        for (const card of this.cards) {
            card.blocked = false;
        }

        // 按层级从上到下检查遮挡
        const layerMap = this.groupByLayer();
        const layers = Array.from(layerMap.keys()).sort((a, b) => b - a);

        for (let i = 0; i < layers.length; i++) {
            const upperCards = layerMap.get(layers[i])!;

            for (let j = i + 1; j < layers.length; j++) {
                const lowerCards = layerMap.get(layers[j])!;

                for (const upper of upperCards) {
                    for (const lower of lowerCards) {
                        if (this.isBlocked(upper, lower)) {
                            lower.blocked = true;
                        }
                    }
                }
            }
        }

        // 更新UI
        this.updateCardsUI();
    }

    /**
     * 遮挡判定（重叠面积超过50%）
     */
    private isBlocked(upperCard: Card, lowerCard: Card): boolean {
        const overlapArea = this.calculateOverlapArea(upperCard.position, lowerCard.position);
        const lowerArea = this.cardSize * this.cardSize;
        return overlapArea / lowerArea > 0.5;
    }

    /**
     * 计算重叠面积
     */
    private calculateOverlapArea(pos1: Vec3, pos2: Vec3): number {
        const halfSize = this.cardSize / 2;

        const left = Math.max(pos1.x - halfSize, pos2.x - halfSize);
        const right = Math.min(pos1.x + halfSize, pos2.x + halfSize);
        const top = Math.max(pos1.y - halfSize, pos2.y - halfSize);
        const bottom = Math.min(pos1.y + halfSize, pos2.y + halfSize);

        if (left >= right || top >= bottom) {
            return 0;
        }

        return (right - left) * (bottom - top);
    }

    /**
     * 按层级分组
     */
    private groupByLayer(): Map<number, Card[]> {
        const map = new Map<number, Card[]>();

        for (const card of this.cards) {
            if (!card.removed) {
                if (!map.has(card.layer)) {
                    map.set(card.layer, []);
                }
                map.get(card.layer)!.push(card);
            }
        }

        return map;
    }

    /**
     * 更新所有卡片UI状态
     */
    private updateCardsUI(): void {
        for (const card of this.cards) {
            if (card.removed) continue;

            const cardNode = this.cardNodes.get(card.id);
            if (!cardNode) continue;

            const cardComp = cardNode.getComponent(LetterCard);
            if (!cardComp) continue;

            if (card.blocked) {
                cardComp.setState(CardState.BLOCKED);
            } else {
                cardComp.setState(CardState.CLICKABLE);
            }
        }
    }

    /**
     * 卡片点击事件
     */
    private async onCardClick(cardId: string): Promise<void> {
        const card = this.cards.find(c => c.id === cardId);
        if (!card || card.removed || card.blocked) {
            console.warn('无法点击该卡片');
            return;
        }

        // 添加到牌槽
        const success = this.slotQueue.addLetter(card.letter);
        if (!success) {
            return;
        }

        // 标记为已移除
        card.removed = true;

        // 播放飞行动画
        const cardNode = this.cardNodes.get(cardId);
        if (cardNode) {
            const targetPos = this.slotQueue.node.getPosition();
            await cardNode.getComponent(LetterCard)?.flyToPosition(targetPos);
            cardNode.destroy();
        }

        // 更新遮挡状态
        this.updateBlockStatus();
    }
}
```

### 9.2 创建音效管理器

在 `scripts/stack/` 创建 `StackAudioManager.ts`：

```typescript
import { _decorator, Component, AudioClip, AudioSource } from 'cc';
const { ccclass, property } = _decorator;

@ccclass('StackAudioManager')
export class StackAudioManager extends Component {
    @property(AudioClip)
    clickCard: AudioClip = null!;

    @property(AudioClip)
    dropSlot: AudioClip = null!;

    @property(AudioClip)
    blinkStart: AudioClip = null!;

    @property(AudioClip)
    clearWord: AudioClip = null!;

    @property(AudioClip)
    expandSlot: AudioClip = null!;

    @property(AudioClip)
    warning: AudioClip = null!;

    @property(AudioClip)
    perfect: AudioClip = null!;

    private audioSource: AudioSource = null!;

    protected onLoad(): void {
        this.audioSource = this.addComponent(AudioSource);
    }

    /**
     * 播放音效
     */
    public play(clip: AudioClip): void {
        if (clip && this.audioSource) {
            this.audioSource.playOneShot(clip, 1.0);
        }
    }

    public playClickCard(): void {
        this.play(this.clickCard);
    }

    public playDropSlot(): void {
        this.play(this.dropSlot);
    }

    public playBlinkStart(): void {
        this.play(this.blinkStart);
    }

    public playClearWord(): void {
        this.play(this.clearWord);
    }

    public playExpandSlot(): void {
        this.play(this.expandSlot);
    }

    public playWarning(): void {
        this.play(this.warning);
    }

    public playPerfect(): void {
        this.play(this.perfect);
    }
}
```
